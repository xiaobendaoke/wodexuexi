## 10-04 集群协同规划叙事重构

研究对象是五架无人机共同承担动态地面计算请求的任务层规划。应急临时空地服务用于解释应用动机，既有实验仍是原动态请求仿真。中心问题依次为：集群飞向哪里以接纳需求、接纳后由谁执行计算任务、两类决策如何通过状态反馈影响时限完成。第三章研究需求感知协同轨迹，第四章研究跨机资源竞争下的固定快照任务分配，第五章研究冻结上层与配额匹配下层的完整在线闭环。

| 统一术语 | 本稿定义与使用边界 |
|---|---|
| 无人机集群 | 五机协作服务系统；不以机数证明大规模可扩展性 |
| 协同轨迹规划／决策 | 简化二维运动模型中的逐时隙服务位置选择；离散位置经环境修复 |
| 计算任务分配／卸载 | 不可拆分计算请求在来源 UAV、允许协作 UAV 和 MBS 间选择执行目标 |
| 自然覆盖接纳 | 当前水平距离满足100 m服务范围，请求在移动前接纳与执行 |
| 分层协同 | 上层 actor 按供给局部观测分散推断，下层集中构图与批量调度；上层训练后冻结 |
| 机间距约束 | 固定200 m离散位置边界；覆盖圆内部不相交由配置决定，不作学习改善主张 |
| 服务效果 | 按原协议报告DSR、接纳、截止期质量、真实UAV能耗、公平性、MBS使用与完整软件时间 |

题目、双语摘要、贡献、六章衔接和架构图同步采用上述定义。新增 Chung 等2018航空集群综述与 Skaltsis 等2023任务分配综述的来源核验，分别支持协同规划背景与分配方法分类，不借综述代替本文性能证据。既有公式与科研结果沿用原证据；飞行动力学、连续避碰、通信受限协同、平台故障与续航作为后续研究问题。

图5-6复用预选回放扩展为五机轨迹、实际航程及最小机间距；灰色地面散点明确为初始UE位置。图5-19从十个训练块的三分支原计数呈现本机、协作UAV和MBS的执行分工，比例分母为三类分支总数，并区分块均值与池化比例。两图均作描述性解释，不构造新显著性检验。本轮无需重训或服务器重放，源数据与核验记录继续保存在原任务目录。

## 09-28 历史协议记录

以下保留原研究路线及当时可用结论，供第三、四章追溯，不作为当前第五章的算法合同。

### 当时可以定稿的中心论断

在自然覆盖接纳的五 UAV、一百 UE 仿真主场景中，请求能否被接纳与接纳后能否按时完成共同决定端到端 DSR。上层 Attention-MAPPO 获得额外的预接纳需求观测、下层采用无注意力学习式卸载的完整候选方法，在现有各方法原配置下相对五个预先指定的学习式对手提高 DSR；相对最强对照的配对差值为 +3.39 个百分点，训练种子 95% 区间为 [+2.13,+4.66] 个百分点。候选独享额外信息，故这不是同信息预算的注意力架构归因，也不证明现实部署效果或全面指标最优。

第三章回答“需求看不见时为何难以接纳、补充预接纳观测是否有效”；第四章回答“已接纳请求还有多少固定快照卸载空间、代价是什么”；第五章回答“完整在线方法相对现有方法是否提高端到端 DSR”。第四章 MC-ITR 未接入第五章在线下层；共享候选轨迹快照桥接只量化质量余量和计算代价，不产生 MC-ITR 的长期 DSR。
