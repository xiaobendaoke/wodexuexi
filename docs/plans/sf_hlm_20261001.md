# SF-HLM 冻结实现与分阶段实验

用户于 2026-10-01 授权实施“面向可服务覆盖的双层学习与负载匹配优化”完整方案。本文记录实现合同及推进条件，不构成性能结论。本任务使用 coverage-optimization 工作树；历史源码、检查点、结果和论文现行主结论保持冻结。

## 实现与信息合同

- [条件化匹配](../../utils/sf_hlm_matching.py)：六个全局执行节点；请求数固定后展开容量槽，使用 SciPy 指派。将合法边能耗缩放至 [0,1]，超时权重取批量请求数加一，实现预测超时数、预测分配能耗的字典序目标。MBS 保持不共享算力。能耗上限通过匹配后筛选，不声称求得含能耗约束的最优解。
- [配额搜索](../../utils/sf_hlm_search.py)：停止及节点间转移 1/2/4 个请求。共同贪心参照能耗乘 1.05；普通 128 次候选评价作为保底。初始任务数的一次匹配包含在 16 次调用内。合法且低于能耗上限的较差中间状态可以继续搜索，只执行保留的最好方案。所有接纳请求完整分配。
- [学习策略](../../marl_models/sf_hlm.py)：两层、128 宽二部图消息传递；集中配额 PPO。监督教师损失独立于 PPO；保存采样时动作 mask、原始动作及概率。Attention-MAPPO 在原观测编码之后融合六项服务压力，消融将摘要置零，保持架构一致。上层 PPO 保存未经裁剪的 Gaussian 动作概率，执行裁剪遵循原映射。
- [运行器](../../scripts/analysis/sf_hlm_experiment.py)：外部冻结源码及套件目录通过参数提供；协议逐文件 SHA-256、训练配置和检查点合同检查。完整评估逐步记录真实计数、预测偏差、能耗、软件耗时、工作负载指纹；按训练种子聚合。两层训练均支持带模型、优化器、随机状态和环境状态的恢复。
- [通信敏感性](../../utils/sf_hlm_coordination.py)：独立新物理协议，使用当前几何的 MBS 回传速率、对称专用串行控制信道和固定二进制消息字节预算；在截止期判定之前增加协调延迟、奖励计算之前增加 UAV 收发能耗。20/100 ms 是额外延迟假设。10% 控制轮丢失时使用源节点单请求局部回退且上层反馈置零；该回退不享有主协议的共同能耗筛选保证，单列丢失率。此模型不是实测部署有效性证据，也未模型化各字段独立失真或不同时隙的持续队列。

仅使用当前请求、当前位置、源节点缓存信念及允许的预测行。当前请求先处理，当前轨迹动作在随后执行；不以移动后链路处理当前请求。自然覆盖半径 100 m、需求观测范围 460 m、不可拆分任务、最终批量共享算力、质量 mask 和实际环境奖励保持原定义。

## 分阶段合同与门槛

1. **结构验证**：A 的五个最后上层检查点，训练块 620001–620005；历史工作负载 720001–720005，每个两回合，在 0/250/500/750 步取 200 个快照，包括空批次。逐步重放历史生成、接纳、成功和分配能耗，检查外生流。比较贪心普通修正、固定任务数匹配、启发式匹配及随机匹配，使用同一参照上限；20/50/100 ms 墙钟曲线包含初始化并记录实际耗时和可能的单次原子调用超时。闭环使用新负载 780001–780005、两回合、1000 步。只有固定匹配或启发式匹配在实际快照和闭环均有正向证据才进入下层训练。探索结果不作为独立确认。
2. **下层训练**：每块独立训练负载 890001–890005；25 回合，每回合八个预定时刻抽图，合计 200 图/块。教师总匹配预算 128（含初始匹配与选中迁移）；5 轮监督预训练，100 次 PPO 更新，每次抽 32 个训练图，在线搜索最多 16 次匹配，8 个 PPO epoch。开发快照不回流训练。闭环同负载比较贪心、启发式、随机、学习；学习须在实际快照减少超时且闭环 DSR 均值改善、种子平均能耗比不超过 1.05、每块完整软件 p95 小于 1 秒才进入上层重训。报告各种子方向与同预算学习−启发式/随机差值；探索性正均值不称确证。1 个百分点的预定成功标准留给整套方法独立确认，不提前要求单独下层承担全部增益。
3. **整套训练及独立确认**：新块 700001–700010、独立训练负载 900006–900015，下层初始化种子由协议逐块列明。完整、无反馈、反馈加启发式、上层加贪心修正、上层加重新训练原下层修正，共 50 次上层训练，200 回合 ×1000 步，原奖励不变。前 50 回合冻结配额下层，其后上层每回合更新，下层每五个完整回合更新一次，单次 rollout 不改变另一层参数。原下层对照按原配置训练，保存原提案概率。最后检查点固定评估 790001–790005，每个六回合，共 250 个评估任务、1500 回合。预定主族为完整−贪心和完整−原学习修正，n=10 配对 t 区间及两比较 Holm；二者均须 DSR 均值增益至少 1 个百分点、区间下界为正、校正 p<0.05、真实总 UAV 能耗比≤1.05，以及软件 p95<1秒。反馈和学习两项机制差另报，不将其混为主检验。
4. **冻结策略稳健性**：仅主确认通过后执行，n=10 ×五新工作负载 791001–791005 ×六回合。完整、贪心、原学习修正三个流程在 60/100/140 UE ×0.6/1.0/1.4 算力的九格评估；上层保持训练时 30 UE 输入容量，旧固定尺寸下层使用填充/分块推理，禁止改变模型权重。再单列两个无丢包计费延迟及一个计费丢包协议，共十二变体。分别报告，不将其当重新训练场景适应结果。

所有组主上层交互预算均为每块 200,000 步。F/N 的额外教师采集每块 25,000 步及离线搜索训练单列；不声称教师数据与计算预算等同于 H/G/L。当前算法为新方法标识与独立检查点合同，并未替换原工厂默认方法。

主指标为实际生成服务请求分母 DSR；潜在请求固定分母、接纳率、接纳后成功率、总 UAV 能耗、公平性、MBS 占比、预测误差及完整软件耗时同时报告。工作负载、回合和请求不作为独立训练重复。软件计时包含观测准备、两层推理、保底修正、匹配搜索和消息编码；环境仿真、结果落盘和未模型化网络传输不属于该软件计时。通信物理代价单列。

失败状态为 `STOPPED_STRUCTURE_GATE`、`STOPPED_LEARNED_GATE` 或 `STOPPED_CONFIRMATION_GATE`，保留全部负面结果，不更新论文成功主张。需要备选联合修正时先基于这些诊断冻结新方案，不自动叠加模块。

### 实现

- [v2 搜索](../../utils/sf_hlm_v2.py)：严格元数据校验；节点分别编码当前与最好方案的六项摘要；每条边分别标记两套分配。请求 4 维、边 14 维、节点 16 维。固定配额 PPO 沿用 1/2/4 与停止动作。
- 临界搜索：与匹配预测一致的整数截止期阈值、1/2/4 加最近释放／安全增量、配额去重、最好加最近两个不同的可行入口。匹配总预算 16（含初始）；保底和共同贪心 1.05 能耗筛选保持一致。第一版没有可学习提前停止。
- [v2 模型](../../marl_models/sf_hlm_v2.py)：两层 128 宽消息传递；每图八轨迹 REINFORCE、其余七条回报均值作基线；奖励、Adam 3e-4、梯度裁剪 0.5、熵 0.005 按批准方案固定。独立 `quota_v2.pt` 合同拒绝旧模型。
- 上层：六项压力、当前可见节点相对位置、MBS 标记组成服务 token；UE 先关注服务 token，再由 UAV 关注需求表示。按全局节点 ID 对齐，仅保留自身、可见邻居与已知 MBS。服务残差和 critic 新输出零初始化。无反馈组压力置零，架构相同。贪心和原学习修正组保持原 Attention actor/critic。
- [确定性采集](../../utils/sf_hlm_rollouts.py)：冻结一个策略版本，同批采集完成后按任务 ID 汇总再更新；SHA256 定义轨迹种子。模型加载后重新设置 Torch 种子，使首次加载和模型缓存命中采用相同采样定义。监督教师不进入 PPO 或分组策略梯度的采样损失。
- [v2 运行器](../../scripts/analysis/sf_hlm_v2_experiment.py)：训练图和闭环评估按回合拆分；重复 reset 前缀与原逐回合执行一致；历史快照重放核对逐步计数和外生指纹。任务独占锁、结果摘要、检查点合同、恢复文件摘要和原始计数复核均启用。最后检查点固定。

### 门槛和分割

A 使用五个原冻结块 620001–620005、训练图负载 890001–890005、开发负载 780001–780005 和历史 200 快照。5 轮监督、100 次 PPO 更新，每次 32 图，在线 16 次匹配。学习相对随机与启发式 DSR 均须 +0.3 个百分点、至少 4/5 块为正，实际快照超时少于贪心修正，真实能耗比≤1.05，完整软件 p95<1 秒。

### 资源与运行

## 2026-10-01 上层适配诊断后的配对实验

800 个检查点评估回合已完成，原结果的 200 个重放及 50 份下层参数核验通过。完整方法第 10/20/30/40/50 回合 DSR 为 35.06/34.31/33.36/33.81/33.59%；冻结上层配额 PPO 为 35.37%。无压力上层同样退化。原网络动作漂移大于新增残差的直接调整。此为五块开发诊断，不挑选中间最高检查点，不启动独立确认。

用户已授权按诊断开展实验。增加 [上层更新与残差模型](../../marl_models/sf_hlm_upper_adaptation.py)、[运行器](../../scripts/analysis/sf_hlm_upper_adaptation.py) 和 [远程验证](../../tests/test_sf_hlm_upper_adaptation.py)，不修改 v1/v2 冻结发布文件。

- **R1 更新器对照**：原 Attention actor/critic＋冻结的新配额 PPO 下层；`original_update` 直接调用冻结源码的 `AttentionMAPPO.update`，对比 `current_update` 的 v2 联合更新。比较的是完整训练器实现包，不能据此分别证明价值裁剪、梯度裁剪或熵项的贡献。五个历史块各两组，50 回合×1000 步，共十次训练。两组从相同历史模型权重及新建优化器开始，不混入历史优化器状态恢复的差异。
