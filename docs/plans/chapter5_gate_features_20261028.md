# 入口前公开特征诊断

日期2026-10-28。启动条件为理想门控主点存在满足原门槛的二值路由。该条件不代表在线可达性。此处在读取特征与收益关系前固定特征清单与图形口径。

只使用候选生成前已有的公开请求行，以及G返回的分配。特征函数不接收物理时延、真实缓存、成功标签、完整方法候选、完整方法耗时或oracle路由。

固定六项特征：接纳批量规模、截止期下四分位数、G在公开平均时延模型加名义10ms下的预测按时比例、G归一化截止期余量下四分位数、G的最大UAV负载占批量比例、每请求平均合法选项数。

各特征独立按全部开发状态的分位点分组，重复分界合并，等值特征不拆分。展示各分组内、各历史块的完整原生方法减G的计费DSR差，块内仍以成功数与实际生成数的加权和求率。全部状态均保留，空块分组显式标明。分组阈值用于描述，不构成冻结的部署阈值。

记录首次提取及后续10次重复的独立特征函数耗时。该计时不含生成请求与求解G的费用，且不是门控完整调用验证，不与C0完整时间直接计算部署加速比。

不拟合分类器，不对分组进行有利方向选择，不扫描最佳阈值，不生成在线路由，不给训练内可分性冠以独立预测能力。结果只判断是否有值得后续检验的可观测关联；若关系弱或跨块不稳，停止推进门控实现。若出现一致关联，也仍需另定留出验证和完整费用协议。
