# 简单入口门控开发协议

2026-10-28。在新门控阈值筛选、完整计时和闭环结果产生前冻结。本轮为开发验证，不是正式非劣效确认。此前两个特征的方向来自全部五个历史块，因此留一块验证只隔离阈值选择，不把特征假设选择也称为盲验证。

## 范围

五方法为原生G、原生完整解析法Full、批量门控A、G公开预测按时比例门控B、双特征门控C。原主方法、上层权重、价格和物理模型只读，不训练模型，不研究增量提议和监控停止，不修改论文，不自动启动独立确认。

门控先计算一次共同G（贪心与最多128次普通修复），在二值初始化匹配和复杂提议之前决策。进入分支复用同一个G，通过原生PricedPolicy原有run逻辑生成、匹配、筛选和选择候选。新适配器仅覆盖初始化入口，不修改封存源码。跳过分支不创建搜索状态，不调用提议、分支解码和匹配器。

公开特征为接纳请求数n、修复后G在公开平均时延加原名义10ms下的预测按时比例q。q直接利用G已经算出的公开预测时延，不计算六项诊断特征，不读取物理执行结果或真实邻机缓存。空批次返回G。A仅使用n，B仅使用q，C使用两者。

## 固定规则族与阈值开发

- A进入完整分支当且仅当`n >= n0`。
- B进入完整分支当且仅当`q < q0`。
- C进入完整分支当且仅当`n >= n0 and q < q0`。
- n0网格为`0,8,12,16,20,24,28,32,40,64`；q0网格为`0,0.25,0.40,0.50,0.60,0.70,0.80,0.90,1.00,1.01`。保留近似全G/全Full端点，不增加规则形状或事后精细搜索。

用原C0固定状态标签和已冻结公开特征表作阈值开发。每折只使用四个块选阈值，剩余块评价；五折全部保留。原C0费用只能作为这一离线开发排序的代理，不能冒充新门控完整费用或与新调用直接相加计算加速比。

训练折筛选要求平均块DSR差不低于−0.05个百分点，每训练块差不低于−0.10个百分点，平均块时间比不超过0.80，两项能耗比均不超过1.05，MBS/接纳差不超过+0.30个百分点。在通过者中优先最大化平均DSR差，随后最小化时间比，再按n0、q0升序打破同分。无通过阈值则该折回退为原生Full，显式记录无可用门控，不为获得节时放宽质量要求。

额外在全部五块上用同一规则选择一次开发规则，单独标记为后续协议参考，不用它评价同批数据的泛化；本轮五块闭环评价始终采用该块未参与阈值选择的折规则。

若三个规则族在全部留一折中均无可用阈值，直接记录开发筛选失败，不运行五种实际相同的Full闭环来制造无意义对照。工程边界验证仍需完成。

## 工程验证与新费用测量

先在1200个固定状态验证强制进入分支与原生Full的候选、动作、预测量和匹配数一致，强制跳过与原生G一致。检查G修复仅调用一次、跳过不触发复杂路径。另检查完整调用反馈、奖励和下一状态在共同固定费用下的等价性。失败时不解释性能，保留技术失败尝试与修正版本。

阈值冻结后，对全部1200状态重新测五方法完整调用，每状态三次重复、每次随机顺序，保留全部计时。原生G与Full也在本轮重计时。完整计时包含门控特征、判断、G复用、下层执行、反馈、上层推理、动作映射及逻辑消息，沿用费用在指标、奖励和下一观测前注入的协议。恢复环境、磁盘日志与离线标签在计时外。不用旧C0耗时作为本轮加速比分母。

## 五方法闭环开发复验

复用五个历史上层块和三个已用开发负载，每方法15个1000步回合，共75回合、75000步。冻结网络参数，配对外生流，允许各方法状态与轨迹分化；不冒充新基座或独立负载。每方法都支付本次实际完整逐次费用。

至多15个单线程进程，分配独立物理核心；一个块/负载束内五方法使用同一核心、固定随机次序。模型加载后设置共同屏障。同一实验内比较，不与旧C0或正式120核调用时钟拼接。烟雾验证通过后才运行完整回合；失败保留记录，不更换有利种子。

独立描述单位为五个历史上层块。块内汇总成功数与生成数，再计算DSR；时间和机队能耗按块内比值再平均。报告完整时间均值、块p95、最大值、进入比例、机队能耗、MBS/接纳和公平性。对A/B/C减Full报告五块差、描述性双侧95%配对t区间及单侧95%下界，不称正式非劣效检验，不增加请求或回合的独立n。

开发点估计门槛保持DSR损失≤0.10个百分点、完整均值时间比≤0.80、机队能耗/Full≤1.05及/G≤1.05。本轮新增MBS容许增量+0.30个百分点为研发设计选择，不追认为原C0门槛；公平性仅描述，沿用全部块p95<1s的经验时间边界。

进入独立确认的开发建议须同时通过上述点门槛，至少4/5块DSR差≥−0.10个百分点、至少4/5块时间比≤0.80，且描述性单侧95%DSR下界≥−0.10个百分点。若只过点门槛而不稳，标为暂缓；没有方法过联合点门槛则停止本轮简单门控路线，不自动增加模型复杂度。

独立确认不在本协议内启动。届时另冻非劣效设计、比较族、独立块/种子、样本量和资源界值，不能复用本轮调参或看过门控结果的数据冒充确认。
