# 自然覆盖下的整套方法对比协议（2026-09-28）

研究问题：在同一自然覆盖仿真系统中，新增未覆盖 UE 观测的分层策略作为**整套方法**，相对仓库已有学习式和非学习式方法的端到端服务表现如何？本实验不识别观测与架构的独立因果贡献。新增信息属于候选方法的组成部分；结论限于接纳前可以得到 460 m 范围内 UE 位置、当前请求签名及电量这一假设，100 m 物理接纳半径保持不变。未计入上报能耗时不得声称真实部署净能耗优势。

冻结后比较的学习方法：`lower_mlp_upper_uncovered_obs`（唯一候选）、`lower_no_attention`（此前最强双层基线）、`hierarchical`、`vanilla_hierarchical`、`ippo`、`joint`。非学习参照：`greedy`、`local`、`mbs`、`random`、`uniform`。后五者按工作负载评估一次，不复制出虚假的训练重复。除候选外保持各已有方法的原配置；不因结果调整模型或奖励。

主场景固定 5 UAV、100 UE、1 MBS，700×700 m；10 个新的训练种子、5 个新的评估工作负载种子，与训练工作负载种子、G4 pilot 和上次独立确认不同。所有学习方法每种子训练 200 回合×1000 步，PPO rollout 1000、epochs 8、batch size 256；每个已训练检查点每个工作负载评估 6 回合。总计 60 次训练、325 个评估任务（其中学习方法 300 个、非学习方法 25 个），共 1950 个评估 episode。短流程烟雾验证只检查可运行性，不计入统计。

主指标为每个评估任务内“满足截止时间请求数 / 全部生成服务请求数”的请求加权 DSR。主比较预先指定候选减去五个学习对手，先对每训练种子的五个配对工作负载差值取平均，再对十个训练种子推断；报告双侧 95% t 区间、配对交叉 bootstrap 区间、未调整和 Holm 校正后的双侧 p 值。只有五个主比较全部为正且 Holm 校正 p<0.05，才称“在本场景中相对所有已有学习方法的 DSR 优势得到支持”；否则逐个限定结论。非学习方法使用工作负载配对描述及区间，不把它们伪装成十个独立训练种子。所有推断均报告实际差值，不把 episode 当独立重复。

并列报告接纳率、已接纳请求截止期满足率、UAV 侧能耗、非飞行分配能耗、公平性、MBS 卸载比例、有效任务/MJ 和训练/推理耗时。次指标用于解释权衡，不能事后替换 DSR 主指标；不把不同方法的训练奖励或有利的单个 seed 用作优越性证明。若能耗、公平性等指标变差，正文必须报告，不能称全面优势。监测评估中外生轨迹是否一致、请求分母与三类失败计数是否闭合、每个任务完整标记与源码哈希是否一致。

实施文件：扩展现有 `run_formal_suite.py` 支持读取锁定的自定义实验清单；在 `scripts/analysis/` 新增整套方法配对统计脚本；在 `tests/` 增加清单与统计回归测试。现有训练实现不改，新候选已在 `run_canonical_experiment.py` 注册。新结果落到独立 `results/whole_system_comparison_20260928/`，任务验收落到 `output/whole_system_comparison_20260928/validation/`，不覆盖既有实验。使用远程 Linux 的 `run_remote_python.sh` 与只读源码快照运行，先短流程后全量，完成后按完成标记、原始评估回合、外生轨迹及聚合表逐层验收。
