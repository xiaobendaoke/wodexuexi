# 可用论文1号

原论文与可追溯实验数据的独立存档，建立日期：2026-10-15。Git分支：`codex/usable-thesis-1`。

论文入口：[阅读PDF](latex/main.pdf)；[编辑LaTeX](latex/main.tex)。保留截至10月14日的原六章稿、40幅在用配图、图源数据及软件费用分析。当前工作区另外新增的三段未核验片段单独存档，不进入有效正文。作者身份、致谢和个人成果中的占位仍待作者核对。

## 文件与编译

- `latex/`：完整正文、参考文献、学校模板和PDF。
- `docs/figures/`：40幅在用图的PDF/SVG/PNG及绘图脚本、图源数据。
- `results/`：第三章需求观测确认、自然覆盖参照、第四章快照/桥接、第五章SF-HLM确认与稳健性、10月14日费用重评分数据。
- `docs/provenance/usable_thesis_1_20261015/`：来源、证据边界、文件指纹及两套原研究源码包。
- `output/usable_thesis_1_20261015/validation/`：本次独立编译、数据与隔离核验；其他output目录为保留的历史记录。

在本目录运行：

```bash
cd latex
make main
```

需要XeLaTeX、BibTeX和latexmk；编译不依赖模型或另一个工作树。重绘依赖Python科学绘图库和中文字体，原研究训练/仿真仍应放在服务器执行。

## 可用数据与证据边界

“可用”指来源可追溯、能够支撑或复核原协议下的结果，不表示论文已满足全部定稿条件，也不表示所有方法都有显著增益。
