\conclusionchapter
\label{cha:conclusion}

本文围绕受限物理覆盖与多节点资源竞争约束下提升无人机集群端到端截止期满足率这一核心主线，依次开展了空地协同计算统一建模、需求感知协同轨迹规划、跨机竞争二元字典序任务分配以及跨时隙持续排队协同控制研究。全文得出的主要研究结论与量化结果如下：

\begin{enumerate}
\item 在空地协同统一建模与受控归因基准方面，在最小安全间距 $d_{\min}=200\,\mathrm{m}=2R_c$ 约束下，各无人机最近邻自然覆盖关联集合严格构成地面已覆盖终端的互斥划分；基于全量实际生成请求计数分母 $G$ 的双因子分解 $\mathrm{DSR}=\alpha\eta$ 与同源工作负载配对对称差分准则，可在协议 I（单时隙批量等份算力共享与动态缓存耦合）与协议 II（跨时隙释放时间与先占式 EDF 串联排队）两套受控实验体系下严格分离前端空间接纳变化与后端资源执行质量变化，避免跨协议指标混拼。

\item 在自然覆盖需求感知轨迹规划（协议 I）方面，瓶颈诊断证实原始已关联观测下未进入覆盖半径的服务请求占生成总数的 $52.13\%$、占全部失败请求的 $68.55\%$，前端空间准入盲区是制约端到端满足率的首要瓶颈。保持 $100\,\mathrm{m}$ 物理覆盖半径与 $295$ 维观测张量不变，按距离优先级补入 $460\,\mathrm{m}$ 感知范围内未覆盖终端并与下层无注意力精简 MAPPO 协同训练后，在 $10$ 个全新训练种子 $\times\ 5$ 个盲测工作负载（累计 $G=9{,}805{,}180$ 个服务请求）独立确认集上，平均自然接纳率由 $47.69\%$ 提升至 $57.51\%$（$+9.82$ 个百分点），推动端到端 DSR 由 $24.50\%$ 显著提升至 $27.35\%$（净增 $+2.85$ 个百分点，配对 $t$ 的 $95\%$ 置信区间 $[+1.65,+4.06]$ 个百分点；其中前端接纳扩张贡献 $+4.87$ 个百分点，后端并发稀释抵消 $-2.02$ 个百分点），同时惩罚系统时延降低 $5.58\,\mathrm{s}$、Jain 公平性指数提升 $+0.0544$。

\item 在固定快照跨机竞争任务分配（协议 I）方面，批量等份算力共享使单请求跨节点迁移同时引发源节点算力释放（$-C_k/F_i$）与目标节点算力稀释（$+C_\ell/F_j$）外部性，仅依据个体时延改善的自利迁移可能恶化系统全局超时数。MC-ITR 在主配置快照上将每快照平均超时请求数由启发式基线的 $2.888$、单遍贪心的 $2.227$ 和自利迭代的 $2.215$ 显著降至 $2.045$（相对自利迭代净减 $-0.170$，$95\%$ 区间 $[-0.222,-0.122]$）；在主配置 $354$ 个可穷举多请求竞争快照（$K\in[2,10]$）上将全局最少超时命中率由自利迭代的 $81.4\%$ 提升至 $92.9\%$（消除了 $67.1\%$ 的剩余超时差距）；在第三章扩展观测确认轨迹抽取的 $400$ 个高密度桥接快照上，将平均超时数由在线下层的 $9.238$ 降至 $6.605$（净减 $-2.633$，$95\%$ 区间 $[-2.925,-2.340]$，其中解除在线配额与个体迭代贡献 $-1.760$、跨机外部性协同搜索贡献 $-0.873$），同时明确了秒级全批次重评估作为离线质量参照的计算时间边界。

\item 在跨时隙持续排队协同控制（协议 II）方面，$816$ 个盲测确认回合（每方案累计 $G=252{,}024$ 个请求）的配对评估表明：缺乏规划引导的联合冷启动 RL（$44.25\%$）难以克服长视距队列信用分配障碍；两轮 DAgger 规划蒸馏将 DSR 由初始先验选择器的 $44.30\%$ 推升至 $48.04\%$（$+3.74$ 个百分点）；受控开关消融证实共同随机数三步反事实辅助模块相对纯在策略暖启动微调（$w_{\mathrm{cf}}=0$，$48.05\%$）独立贡献 $+0.69$ 个百分点，使零在线前瞻联合微调达到 $48.74\%$（较蒸馏显著提升 $+0.70$ 个百分点，$31$ 项 Bonferroni 区间 $[+0.39,+0.98]$ 个百分点），并将单步平均耗时较在线规划基线（$1.602\,\mathrm{s}$，$48.56\%$）降低 $67.5\%$ 至 $0.520\,\mathrm{s}$；进一步结合神经引导 Top-6 MPC 后全程 DSR 达 $49.31\%$（较在线规划显著提升 $+0.75$ 个百分点，高峰期净增 $+1.30$ 个百分点），平均耗时降低 $54.9\%$ 至 $0.722\,\mathrm{s}$，显著推进了服务质量—在线推理耗时的帕累托前沿。
\end{enumerate}

在方法论层面，本文的主要创新贡献体现于以下三个方面：

\begin{enumerate}
\item 揭示了自然覆盖准入下的预接纳观测混叠与梯度盲区机理，提出了零扩维感知域未覆盖需求扩展观测协同轨迹规划方法。突破既有研究或假定全场终端特权已知、或仅观测已关联终端导致圈外需求不可见的局限，从分散式策略得分函数局部可辨识角度形式化证明了预接纳观测盲区性质，在不放宽物理覆盖半径且不增加网络输入维度的条件下按距离序注入感知域未覆盖活跃需求，与精简无注意力下层形成稳健的跨层协同演化。

\item 建立了计入同批算力共享外部性的严格二元字典序分配模型，提出了基于克隆快照全批次重评估的多轮协同迭代算法（MC-ITR）。克服了多指标线性加权折合异质量纲以及按个体预测代价贪心迁移忽视同机他任务超时风险的不足，精确刻画了单请求迁移对源节点与目标节点同批其余任务的算力外部性，依托冻结真实缓存的无序偏置全批次字典序重评估实现了全局超时优先下降与邻域局部最优保障。

\item 提出了融合释放时间串联排队近似、两轮规划知识蒸馏、共同随机数反事实组辅助微调与熵自适应 Top-6 MPC 的跨时隙动态排队协同控制方法。针对持续排队场景中跨阶段预约偏差、高外生到达方差与全候选滚动推演高耗时的核心矛盾，构建了通信释放时刻递推耦合先占式 EDF 计算的两阶段近似算子与槽位置换同变双分支策略网络，通过同源随机流反事实组中心化消除公共到达波动，并借助熵自适应对数先验权重校准实现了零前瞻快速推理与低开销滚动验证的有机统一。
\end{enumerate}

在未来的研究中，还将围绕复杂低空环境适配、跨协议统一闭环建模与边缘/机载实时验证开展进一步探索：一方面结合城市三维建筑高程地图与概率视距/非视距阴影衰落信道开展三维避障轨迹规划，在相同感知范围未覆盖扩展观测下横向对比不同上层集合编码结构与显式需求质心启发式的独立表征贡献，并将移动终端演化、动态服务缓存预取与跨时隙先占式排队纳入统一端到端训练闭环；另一方面针对跨时隙排队候选准备与串联队列特征提取中的解释器循环开销，采用增量算术加速、C++ 编译型并行内核与候选批量向量化将常规在线求解延迟压缩至毫秒量级，显式计入非理想控制信令与计算等待时延并结合本地 $(k_{\mathrm{safe}},\mathbf{0})$ 安全回退机制，在硬件在环平台与真实无人机集群试验中检验所提方法的工程实用性。
