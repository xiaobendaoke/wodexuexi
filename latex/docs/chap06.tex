\chapter{总结与展望}
\label{cha:conclusion}

\section{研究总结}
\label{sec:ch6-summary}

本文面向具有截止时间的地面计算服务，研究无人机集群如何通过协同空间部署接纳动态需求，并通过跨节点计算任务分配提高按时完成比例。空中平台的位置决定请求能否进入服务流程，机载计算、缓存及协作传输决定接纳后的执行质量。围绕这两个相互联系的环节，本文以统一请求计数为基础，依次研究需求感知协同轨迹决策、固定快照跨机任务分配和 SF-HLM 完整在线方法，形成从空间服务瓶颈到批量资源耦合再到分层决策验证的技术路线。

研究聚焦无人机集群的任务规划与资源分工：机动决策调整服务区域，任务分配组织执行节点，共同服务于时限完成目标。MEC 提供具有明确输入、截止时间和资源消耗的任务模型。方法在固定高度二维运动和规定信息条件下评价，其适用范围及进一步面向飞行执行的需求见下文。

\subsection{需求感知的集群空间部署与服务接纳}
\label{sec:ch6-observation-summary}

本文把实际生成、自然接纳和按时完成的服务请求记为 $G$、$A$ 和 $S$，以 $S/G$ 定义端到端 DSR，同时报告 $A/G$ 与 $S/A$。这一口径把未覆盖请求的损失纳入评价，使轨迹控制与卸载质量能够在同一个服务成功链条内解释。它也避免了只看接纳后完成率时忽略覆盖盲区的问题。对于多个时隙、工作负载或训练块，本文按照预定计数和聚合层次计算指标，而不直接相乘三个跨单元均值。

第三章的服务失败分析显示，未覆盖需求构成主场景中重要的失败来源。扩展上层预动作观测后，轨迹策略能够看到感知范围内尚未接纳的用户，其物理服务半径仍为 $100\,\mathrm{m}$。独立确认中，候选 DSR 从 $0.2444$ 增至 $0.2793$，提升约 $3.49$ 个百分点，并在十个训练种子上保持同向。接纳增加的同时，接纳后完成质量发生变化，这使“更多覆盖”与“更好的服务”之间的联系成为后续卸载研究的直接动机。固定潜在服务请求分母复核也表明，轻微实际分母变化未解释该批次的主增益。

这项研究把轨迹规划的依据从已接纳用户扩展到允许观测的尚未接纳需求，使集群空间部署能够面向后续服务机会进行调整。邻机与用户注意力组织可变的空间交互信息，位移、边界和间距修复保证规定离散状态中的几何可行性。需求信息扩展同时改变了信息条件；同信息预算的探索性替代结构比较尚未确认独立注意力优势，因此本文把需求可见性、网络聚合和环境执行约束分别解释。这种区分保留了空间部署改善的证据，也使后续结构比较能够围绕相同信息条件进行。

\subsection{跨机计算任务分工与批量资源耦合}
\label{sec:ch6-snapshot-summary}

第四章针对给定集群位置、请求和历史状态研究 MC-ITR，把跨机任务分工写成具有批量外部影响的分配问题。最终批量均分算力使一个请求迁移能够改变两个节点上其他请求的完成时间，因此逐请求自身代价不足以完整描述迁移影响。MC-ITR 对候选迁移重新评价整个分配，并按超时数、归一化时延与分配能耗的字典序比较接受严格改善。有限分配空间与严格改善保证相应搜索按无改善或预算条件终止，其性质属于固定快照求解过程；完整邻域扫描无改善时才认证相应邻域局部最优。

主配置中，MC-ITR 每快照平均超时数为 $2.055$，低于 Iterative-Base 的 $2.228$；主配置及八个 UE 或算力敏感性配置的配对结果支持其截止期质量改善。小规模穷举提供实现一致性检查。在需求感知上层与无注意力学习式下层产生的共享轨迹快照上，MC-ITR 相对在线下层平均每快照少 $2.460$ 个超时请求，进一步显示固定状态下的分配余量。

固定快照实验同时显示质量改善的代价。学习轨迹快照上，MC-ITR 分配能耗约增加 $23.8\%$，含贪心初值的完整调用路径平均约 $20.751\,\mathrm{s}$。反事实分配未回写环境，这些结果刻画的是给定状态下的质量--计算权衡。MC-ITR 作为离线参照，其批量资源分析为条件化匹配与有限预算在线搜索提供了设计依据。

\subsection{协同轨迹与计算任务分配的分层决策}
\label{sec:ch6-sfhlm-summary}

第五章提出并验证 SF-HLM，连接需求感知空间部署与接纳后的计算资源分工。给定执行节点配额后，将请求分配到容量槽位，通过条件化指派处理请求身份与最终共享算力之间的关系；CompleteQuotaPPO 选择配额迁移与停止动作。共同质量掩码、普通修复、能耗筛选和最好方案保留，使有限预算搜索输出完整分配。训练时保持上层参数固定，独立优化配额策略，在线执行沿用自然接纳和请求处理时序。

十个独立训练块与五个配对工作负载的确认中，SF-HLM 的 DSR 为 $34.244\%$，相对贪心加普通修复、冻结请求级下层加修复、适配请求级下层加修复，分别提高 $1.423$、$2.008$ 和 $2.192$ 个百分点。相对相同学习上层加逐请求随机卸载与全随机，分别提高 $10.604$ 和 $18.816$ 个百分点。上述对照评价完整下层优化框架和完整系统的收益；学习搜索的增量由共享框架对照进一步刻画。SF-HLM 接纳后按时完成率约为 $59.82\%$，显示下层任务组织对服务质量的作用。

共享强框架下，配额随机搜索已经达到约 $34.100\%$ DSR，学习搜索的额外差值约为 $0.143$ 个百分点。配对区间约为 $[0.006,0.281]$ 个百分点，机制族 Holm 校正通过，而精确符号翻转敏感性结果接近临界。这一较小增量及其统计敏感性表明，完整框架构成了主要收益来源。SF-HLM 各块隔离 p95 软件调用时间的均值约为 $109.24\,\mathrm{ms}$，高于强配额随机的约 $73.47\,\mathrm{ms}$；学习搜索提供小幅服务质量增益，同时增加软件开销。

逐次软件费用的事后复核进一步限定了学习增量的用途。原确认轨迹中，加入各方法实际记录的软件等待后，学习DSR为 $29.379\%$，低于强随机的 $30.073\%$ 和贪心的 $32.161\%$。该评分没有改变轨迹或跨步资源状态，但表明原未扣除调度等待的服务优势不能直接转化为在线净收益。当前方法的主要贡献是批量结构化求解及其质量--费用分析；选择学习搜索时，需要同时考虑请求余量和求解成本。

\section{综合认识与适用范围}
\label{sec:ch6-interpretation}

两类决策具有互补作用：轨迹策略依据预动作需求信息改变未来空间服务条件，结构化下层依据已接纳请求与节点能力协调当前资源竞争。位置、缓存和能量按批次评价规则将二者连接为闭环，未完成任务和下载事件不跨步保留；DSR 分解用于描述接纳与完成质量的共同变化。完整方法的效果由独立确认评价，固定快照和探索性消融则提供结构解释。

集群采用上层分散式决策与下层集中调度。各 UAV 的 Actor 使用规定的局部观测，下层汇总当前请求和节点能力形成任务分配，因此仍需集中协调。五机仿真尚未检验大规模通信扩展性；$460\,\mathrm{m}$ 感知范围规定观测邻居集合，$200\,\mathrm{m}$ 最小间距规定离散几何约束。持续通信连通性与连续飞行安全需要对应的通信及运动模型验证。

固定策略稳健性评价覆盖 $60/100/140$ UE 与 $0.6/1.0/1.4$ UAV 算力的九格设置，检验相同模型在负载与算力变化下的表现。相对三个主对照，完整下层优化保持正向增益；相对强配额随机的学习增量则具有场景依赖。固定 MBS 配额和墙钟预算诊断进一步刻画相同快照上的匹配行为与计算限制，与长期闭环评价相互补充。

研究采用仿真信息与理想协调条件，尚未计入预接纳需求上报、通信排队、消息失真和现实网络等待。软件计时包含输入准备、推理与搜索路径，能耗统计覆盖 UAV 飞行与作业，未覆盖全部地面计算及新增控制通信费用。节点能力和计算能耗采用等效频率假设，参数没有指定机载芯片的标定。所报告能耗改善仅适用于这一模型，不换算为实测续航收益；服务主指标未计求解等待，部署净收益仍需在完整通信与能源模型中检验。

\section{后续研究方向}
\label{sec:ch6-future}

首先，可把任务层机动决策与具有飞行动力学约束的轨迹执行连接。当前位移模型限制速度模长、边界和离散机间距，但没有描述加速度、转向、姿态及环境扰动。后续需要检查这些约束如何改变可到达服务位置，并把轨迹跟踪误差纳入覆盖判定。在相同请求与资源条件下，比较理想位置更新和动力学可执行轨迹的接纳率、按时完成率及实际飞行能耗，可以判断现有任务层收益在执行约束下保留多少。连续避碰能力也应由对应轨迹验证与控制分析确认。

其次，可研究预接纳信息与集中协调信息的实际获取条件。分别设置请求上报延迟、字段缺失、更新频率和控制消息代价，并在截止期判定与能耗结算中计入请求汇总、分配下发等开销。各方法使用相同信息条件和回退规则，比较信息陈旧或通信受限时的服务质量，由此确定当前理想协调收益的保留程度。

再次，可研究平台失效与有限续航条件下的集群任务重分工。在现有能耗模型基础上，增加剩余能源、返航保留量和失效时刻；执行节点不可用时重新确定配额、任务映射和空间部署，并记录任务丢失与恢复时间。在固定故障流和相同电池预算下评价服务恢复能力，使续航与失效适应具有直接的实验依据。

在决策模型方面，可扩大同信息结构比较与场景训练设计。第三章已有同信息替代结构的探索性证据，后续可以用新的训练块和负载进行确认，检查注意力聚合、需求排序与观测容量各自的作用。对于 UE 与算力变化，也应区分冻结策略泛化和重新训练适配：前者关注已有模型是否仍可用，后者关注在新场景下投入额外训练能达到什么表现。这样的分开设计能够为模型选择和集群服务预算提供更清楚的依据。

在任务调度方面，可研究更有效的有限预算搜索。当前强配额随机已具有较高服务质量，说明条件化匹配与保留框架提供了坚实基座；学习策略的下一步应针对请求临界程度、负载变化和调用成本形成更准确的停止与入口选择。在相同匹配预算和墙钟预算下，比较不同学习信号与教师路径，报告在线收益以及离线标注成本。任何由开发结果筛选的新策略，应使用新的独立确认，而不直接替换当前主结果。

上述扩展还可以结合传播遮挡、请求依赖和缓存不确定性，逐步检验更丰富的物理与业务条件。扩展模型时应保持单位、时序与成功计数一致，并继续保留强非学习对照。实际执行轨迹、注意力权重和搜索过程的可视化可以帮助解释行为，但应来自冻结模型与完整记录，不能替代独立性能检验。对于应急临时服务等应用，还需使用相应的地理环境、任务流和平台参数独立验证，才能把本文的仿真服务收益转化为具有明确机动、能源与信息成本的集群系统设计依据。

\section{本章小结}
\label{sec:ch6-closing}

本文围绕需求感知空间部署、跨机批量任务分配和 SF-HLM 分层决策，建立了从服务接纳到截止期完成的集群规划方法。原批次评分的独立确认支持完整下层优化框架在所测主场景中的 DSR 改善，强随机对照则显示学习搜索增量较小。事后软件费用复核显示方法排序可能反转，进一步界定了这一改善的适用口径。后续结合动力学执行、通信受限协调、平台失效与有限续航模型，可进一步检验该方法的适用范围。
