\chapter{总结与展望}
\label{cha:conclusion}

\section{研究总结}
\label{sec:ch6-summary}

本文面向具有截止时间的地面计算服务，研究无人机集群如何通过协同空间部署接纳动态需求，并通过跨节点计算任务分配提高按时完成比例。空中平台的位置决定请求能否进入服务流程，机载计算、缓存及协作传输决定接纳后的执行质量。围绕这两个相互联系的环节，本文以统一请求计数为基础，依次研究需求感知协同轨迹决策、固定快照跨机任务分配和 SF-HLM 完整在线方法，形成从空间服务瓶颈到批量资源耦合再到分层决策验证的技术路线。

本文的研究对象属于无人机集群任务规划与资源分工。机动决策使多个服务区域随需求调整，任务分配使多个执行节点分担接纳负载，共同服务于时限完成目标。MEC 为这种协同提供了具有明确输入、截止时间和资源消耗的任务模型。本文在固定高度二维运动与规定信息条件下检验方法，不将应急服务这一应用动机等同于已完成灾害场景验证，也不把任务层协同扩展为飞行动力学或编队稳定性的研究结论。

\subsection{需求感知的集群空间部署与服务接纳}
\label{sec:ch6-observation-summary}

本文把实际生成、自然接纳和按时完成的服务请求记为 $G$、$A$ 和 $S$，以 $S/G$ 定义端到端 DSR，同时报告 $A/G$ 与 $S/A$。这一口径把未覆盖请求的损失纳入评价，使轨迹控制与卸载质量能够在同一个服务成功链条内解释。它也避免了只看接纳后完成率时忽略覆盖盲区的问题。对于多个时隙、工作负载或训练块，本文按照预定计数和聚合层次计算指标，而不直接相乘三个跨单元均值。

第三章的服务失败分析显示，未覆盖需求构成主场景中重要的失败来源。扩展上层预动作观测后，轨迹策略能够看到感知范围内尚未接纳的用户，其物理服务半径仍为 $100\,\mathrm{m}$。独立确认中，候选 DSR 从 $0.2444$ 增至 $0.2793$，提升约 $3.49$ 个百分点，并在十个训练种子上保持同向。接纳增加的同时，接纳后完成质量发生变化，这使“更多覆盖”与“更好的服务”之间的联系成为后续卸载研究的直接动机。固定潜在服务请求分母复核也表明，轻微实际分母变化未解释该批次的主增益。

这项研究把轨迹规划的依据从已接纳用户扩展到允许观测的尚未接纳需求，使集群空间部署能够面向后续服务机会进行调整。邻机与用户注意力组织可变的空间交互信息，位移、边界和间距修复保证规定离散状态中的几何可行性。需求信息扩展同时改变了信息条件；同信息预算的探索性替代结构比较尚未确认独立注意力优势，因此本文把需求可见性、网络聚合和环境执行约束分别解释。这种区分保留了空间部署改善的证据，也使后续结构比较能够围绕相同信息条件进行。

\subsection{跨机计算任务分工与批量资源耦合}
\label{sec:ch6-snapshot-summary}

第四章针对给定集群位置、请求和历史状态研究 MC-ITR，把跨机任务分工写成具有批量外部影响的分配问题。最终批量均分算力使一个请求迁移能够改变两个节点上其他请求的完成时间，因此逐请求自身代价不足以完整描述迁移影响。MC-ITR 对候选迁移重新评价整个分配，并按超时数、归一化时延与分配能耗的字典序比较接受严格改善。有限分配空间与严格改善保证相应搜索按无改善或预算条件终止，其性质属于固定快照求解过程；完整邻域扫描无改善时才认证相应邻域局部最优。

主配置中，MC-ITR 每快照平均超时数为 $2.055$，低于 Iterative-Base 的 $2.228$；九个主场景、UE 和算力变体的配对结果支持其质量改善。小规模穷举用于实现一致性检查，不能被外推为主配置全局最优证明。在历史候选轨迹产生的共享快照上，MC-ITR 相对在线下层平均每快照少 $2.460$ 个超时请求，说明这些状态中仍存在可利用的分配余量。

固定快照实验同时测量了代价。共享轨迹桥接中，MC-ITR 分配能耗约增加 $23.8\%$，含贪心初值的完整调用路径平均约 $20.751\,\mathrm{s}$。这项结果为较快的近似优化提供了设计依据，但反事实分配未回写环境，不能与第五章长期 DSR 直接相加。本文没有将 MC-ITR 接入在线下层，而是用其揭示的批量结构指导后续条件化匹配与有限预算搜索。

\subsection{协同轨迹与计算任务分配的分层决策}
\label{sec:ch6-sfhlm-summary}

第五章提出并验证 SF-HLM 的当前主线实现，连接需求感知的集群空间部署与接纳后的计算资源分工。给定执行节点配额后，把自然接纳请求分配到容量槽位，通过条件化指派处理请求身份与最终共享算力之间的关系；CompleteQuotaPPO 再选择配额迁移与停止动作。共同质量掩码、普通修复、能耗筛选和最好方案保留构成可执行优化框架，使有限预算中的搜索能够保留已发现的完整方案。该主线采用冻结学习式上层和独立训练的配额策略，保持原自然接纳和物理执行语义。

十个独立训练块与五个配对工作负载的确认中，学习配额搜索的 DSR 为 $34.244\%$，相对贪心加普通修复、原冻结学习下层加修复、原适配学习下层加修复，分别提高 $1.423$、$2.008$ 和 $2.192$ 个百分点。相对相同学习上层加逐请求随机卸载与全随机，差值分别为 $10.604$ 和 $18.816$ 个百分点。这些对照分别说明完整下层优化包与完整系统相对随机决策的收益，不能全部归因于配额 PPO。候选接纳后按时完成率为约 $59.82\%$，表明下层质量是最新主线的重要增益环节。

共享强框架下，配额随机搜索已经达到约 $34.100\%$ DSR，学习搜索的额外差值约为 $0.143$ 个百分点。原配对区间为约 $[0.006,0.281]$ 个百分点，机制族 Holm 校正通过，而精确符号翻转敏感性结果接近临界。因此，学习额外收益应按较小效应解释，同时保留强框架本身的主要贡献。主线各块隔离 p95 软件调用时间的均值约为 $109.24\,\mathrm{ms}$，高于强配额随机的约 $73.47\,\mathrm{ms}$；服务质量提升与软件开销必须共同呈现。

\section{综合认识与适用范围}
\label{sec:ch6-interpretation}

本文的方法组织体现了无人机集群规划中的两个互补方向：轨迹策略面对尚未接纳的需求，改变未来空间服务条件；结构化下层面对已经接纳的请求，协调当前跨节点资源竞争。前者依赖允许的预动作信息，后者依赖当前请求、节点和预测模型。闭环中缓存与能量会让二者继续互相影响，因此本文把 DSR 分解作为解释框架，而不主张各组件收益可以独立相加。最新确认是完整方法的实验结论，固定快照和开发消融用于解释其结构与边界。

集群协调采用上层分散式决策与下层集中调度相结合的方式。每架 UAV 的 Actor 使用按信息合同提供的局部观测，下层则汇总当前请求和节点能力形成完整任务分配。这种组织体现了空间部署与计算分工的协同，但仍需要集中协调条件。当前五机仿真没有检验大规模集群的通信扩展性，也没有把 $460\,\mathrm{m}$ 感知邻居关系作为持续通信连通性证明。$200\,\mathrm{m}$ 最小间距属于既定离散几何约束，不能被解释为学习方法独立获得的连续飞行安全能力。

冻结策略稳健性评价已经覆盖 $60/100/140$ UE 与 $0.6/1.0/1.4$ UAV 算力的九格设置，不再属于尚未完成的工作。这些评价检验相同冻结模型面对负载与算力变化的表现，不等于各场景重新训练后的最优适配。完整下层优化与强配额随机之间的差异仍依赖场景，不能由主场景小幅正效应推断所有变体均有显著学习优势。固定 MBS 配额和墙钟预算的快照诊断则进一步明确了匹配行为和计算限制，但不替代长期闭环比较。

现有研究采用仿真信息与理想协调条件，预接纳需求上报、通信排队、消息失真以及实测网络时延尚未被最新确认结果覆盖。软件计时包含协议规定的观测准备、推理与搜索路径，但不包含未建模的现实传输等待。UAV 能耗统计也不等于全系统能源足迹。本文结论因此限定为当前仿真、信息合同与冻结配置下的性能，不据此宣称所有指标全面最优或已经满足真实部署要求。

\section{后续研究方向}
\label{sec:ch6-future}

首先，可把任务层机动决策与具有飞行动力学约束的轨迹执行连接。当前位移模型限制速度模长、边界和离散机间距，但没有描述加速度、转向、姿态及环境扰动。后续需要检查这些约束如何改变可到达服务位置，并把轨迹跟踪误差纳入覆盖判定。在相同请求与资源条件下，比较理想位置更新和动力学可执行轨迹的接纳率、按时完成率及实际飞行能耗，可以判断现有任务层收益在执行约束下保留多少。连续避碰能力也应由对应轨迹验证与控制分析确认。

其次，可在明确通信协议下研究预接纳信息与集群协调信息的可获得性。现有策略看到感知范围内的位置、请求和电量，后续应分别设置请求上报延迟、字段缺失、更新频率和控制消息代价，并在截止期判定与 UAV 能耗结算之前计入相应成本。下层集中调度还应计入请求汇总与分配下发的时延，检查信息陈旧时的可行性与回退行为。所有方法应使用相同信息条件和回退规则，使性能差异能够对应算法而不是隐含信息优势。该试验属于新物理或观测协议，需要独立冻结配置与评价，不能把理想协调结果直接延伸为部署结论。

再次，可研究平台失效与有限续航条件下的集群任务重分工。当前研究记录 UAV 飞行与任务执行能耗，尚未通过有限机载电池状态决定返航、退出服务或续航终止。后续应明确各机剩余能源、返航保留量和失效时刻，在执行节点不可用时重新确定配额、任务映射和空间部署，并记录任务丢失与恢复时间。固定故障流和相同电池预算下的比较，能够检验现有层次结构是否支持能力变化后的服务恢复；这种能力不能由当前平均能耗较低或任务迁移收益直接推断。

在决策模型方面，可扩大同信息结构比较与场景训练设计。第三章已有同信息替代结构的探索性证据，后续可以用新的训练块和负载进行确认，检查注意力聚合、需求排序与观测容量各自的作用。对于 UE 与算力变化，也应区分冻结策略泛化和重新训练适配：前者关注已有模型是否仍可用，后者关注在新场景下投入额外训练能达到什么表现。这样的分开设计能够为模型选择和集群服务预算提供更清楚的依据。

在任务调度方面，可研究更有效的有限预算搜索。当前强配额随机已具有较高服务质量，说明条件化匹配与保留框架提供了坚实基座；学习策略的下一步应针对请求临界程度、负载变化和调用成本形成更准确的停止与入口选择。在相同匹配预算和墙钟预算下，比较不同学习信号与教师路径，报告在线收益以及离线标注成本。任何由开发结果筛选的新策略，应使用新的独立确认，而不直接替换当前主结果。

上述扩展还可以结合传播遮挡、请求依赖和缓存不确定性，逐步检验更丰富的物理与业务条件。扩展模型时应保持单位、时序与成功计数一致，并继续保留强非学习对照。实际执行轨迹、注意力权重和搜索过程的可视化可以帮助解释行为，但应来自冻结模型与完整记录，不能替代独立性能检验。对于应急临时服务等应用，还需使用相应的地理环境、任务流和平台参数独立验证，才能把本文的仿真服务收益转化为具有明确机动、能源与信息成本的集群系统设计依据。

\section{本章小结}
\label{sec:ch6-closing}

本文完成了面向时限服务的无人机集群需求感知协同轨迹决策、跨机批量任务分配和最新 SF-HLM 分层方法的研究。独立确认支持完整下层优化包在当前主场景中提高端到端 DSR，强随机对照则限定了学习搜索额外贡献的幅度。由此形成的任务规划思路是在规定机动与信息条件下，让空间部署改善服务接纳，再让跨节点资源分工改善接纳后的执行质量。后续研究围绕动力学可执行性、通信条件、平台失效与有限续航进一步检验这一思路，并继续保持已有方法、数据和主结果的可追溯性。
