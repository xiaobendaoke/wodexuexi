\chapter{总结与展望}
\label{cha:conclusion}

\section{研究总结}

本文在自然覆盖接纳规则下研究多无人机 MEC 的轨迹与任务卸载协同决策。服务请求只有进入 UAV 的物理覆盖范围才被接纳；端到端截止期满足率以全部\emph{实际生成}的服务请求为分母。因此，轨迹造成的接纳变化与卸载造成的接纳后完成质量必须同时报告。

第三章的瓶颈诊断显示，未覆盖请求是当前主场景服务失败的重要来源。在下层配置相同、分别训练的独立确认实验中，扩展上层对 $460\,\mathrm{m}$ 范围内未接纳 UE 的预动作观测后，DSR 从 $0.2444$ 增至 $0.2793$；接纳率上升，但该批次的接纳后按时完成率下降。这个结果支持观测方案在仿真主场景中的效果，也揭示单纯扩大接纳可能带来的服务压力。

第四章在固定轨迹快照上比较卸载分配。MC-ITR 每快照平均超时数为 $2.055$，低于 Iterative-Base 的 $2.228$，但需要更多分配能耗与求解时间。小规模穷举与 MC-ITR 的目标分量一致，但 Greedy-Single-Pass 和 Iterative-Base 在该简单配置下也达到相同均值。第五章进一步在候选轨迹快照上作定量桥接：MC-ITR 相对在线下层平均每快照少 $2.460$ 个超时请求，归一化分配能耗约高 $23.8\%$，完整调用路径平均约 $20.751\,\mathrm{s}$。该方法未接入在线系统；固定快照收益不能与第五章 DSR 直接相加，现有计时也不足以支持 $1\,\mathrm{s}$ 时隙内的实时执行主张。

第五章在十个训练种子和五个配对工作负载的主场景对比中，完整候选方法的 DSR 为 $0.2798$，最强已有学习式双层对照为 $0.2459$，差值 $3.39$ 个百分点，训练种子配对 $95\%$ 区间为 $[2.13,4.66]$ 个百分点。相对五个预定学习对手的 DSR 主比较均通过 Holm 校正后的双侧检验。这证明的是现有方法各自原配置下、所评估一百 UE 仿真场景中的整套方法差异。不同对手间的接纳率、接纳后质量和 UAV 能耗存在不同方向的权衡，不能概括为全面性能最优。

\section{限制与后续工作}

当前候选方法额外获得 $460\,\mathrm{m}$ 范围内未接纳 UE 的位置、请求特征和电量；预接纳信息的上报时序、丢失、通信开销及能耗尚未建模。下一步应在相同信息预算下与强对照方法比较，并使用仅位置、延迟请求和计入上报代价等协议，验证优势是否仍然存在。各方法实际生成服务请求的分母受到 UE 电池状态影响；用共同的固定潜在服务请求分母重算已保持主场景 DSR 优势，但它不等于改变请求生成协议的反事实实验。

候选整套方法尚未完成 UE 数量与算力变化下的配对复验；本论文因此不声称跨负载与算力稳健。第五章的桥接实验已量化 MC-ITR 在候选轨迹固定快照上的质量余量与计算代价，但没有使 MC-ITR 参与闭环决策，不能据此推断它将提高长期 DSR。若将来要把固定快照搜索结果用于在线方法，应另行设计快速近似或蒸馏机制，并通过独立训练、配对评估和实际调用时间验证，而不能直接沿用本章的反事实差值。

\section{本章小结}

本文现阶段最有力的结论是：在自然覆盖的一百 UE 仿真主场景中，加入预接纳需求观测的完整分层方法，相对预定的现有学习式方法提高了端到端 DSR。对于增益的独立架构归因、现实信息可得性和跨场景稳健性，仍应保持明确的证据边界。
