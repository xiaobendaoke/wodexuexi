\chapter{总结与展望}
\label{cha:conclusion}

\section{工作总结}
\label{sec:summary}

本文提出基于 Attention-MAPPO 的多无人机 MEC 轨迹与任务卸载协同优化框架。该框架将轨迹控制和请求级卸载分解为两个协同决策层，以降低直接端到端联合动作建模的结构复杂度。系统中，服务请求优先关联至自然覆盖范围内的 UAV；未被自然覆盖的请求按照最近 UAV 原则关联，并在真实链路条件下进入后续处理流程。

本文的主要工作和贡献包括：

\begin{enumerate}
    \item 提出了基于 Attention-MAPPO 的双层 MARL 框架，将轨迹控制与请求级卸载解耦为上层和下层两个协同决策层，降低动作空间复杂度。
    \item 设计了质量感知动作掩码和拉格朗日约束机制，分别处理不可行动作屏蔽和 DSR-MBS 负载权衡问题。
    \item 显式建模了 UAV 飞行能耗、UE 电池动态和 WPT 机制，并在系统模型中定义服务请求关联与处理流程。
\end{enumerate}

实验结果表明：
\begin{enumerate}
    \item 综合对比实验中，本文方法取得最高公平性（0.9452）、最低 UAV 侧能耗（49.98M）和最低 MBS 负载比例（3.59\%），同时保持 0.3762 的 DSR，体现出低能耗、高公平性和低 MBS 依赖的综合折中优势。
    \item 与 IPPO 和 Vanilla MAPPO 相比，本文方法的 DSR 更高且 MBS 依赖更低；与 Joint MAPPO 和 Uniform 相比，本文方法虽然不是最高 DSR，但能耗和 MBS 负载更低，公平性更高。
    \item 主配置和模块消融结果表明，上层轨迹控制主要改善自然覆盖水平和空间公平性，下层请求级卸载主要调节本地、协作和 MBS 执行分布；拉格朗日软约束对抑制 MBS 依赖最为关键。
    \item 端到端联合 MAPPO 的 DSR 为 0.4163，但其系统奖励、能耗、公平性和 MBS 负载均明显劣于分层策略，说明直接联合学习轨迹与卸载动作具有更高的综合代价。
    \item 参数敏感性实验进一步显示，在 UE 数量和 UAV 算力变化下，本文方法通常保持高于普通 MAPPO 的 DSR 和有效能效，并在负载升高时维持较高公平性，验证了其作为综合折中策略的稳定性。
\end{enumerate}

\section{未来展望}
\label{sec:future-work}

本文工作仍可从以下方向进一步扩展：

\begin{enumerate}
    \item 在更多 DSR 阈值和权重组合上进行细粒度 Pareto 扫描，以更好地理解 DSR、能耗和公平性之间的权衡关系。
    \item 扩大各对比方法的训练随机种子与工作负载随机种子规模，以提高实验结论的统计可靠性。
    \item 引入三维轨迹控制以更好地模拟真实部署环境，考虑 UAV 飞行高度的变化对通信和能耗的影响。
    \item 研究更高效的 Lagrange 乘子自适应更新策略，以提高约束优化的收敛速度和稳定性。
    \item 将服务缓存和内容分发纳入协同优化框架，实现轨迹、卸载、缓存和资源分配的全面协同优化。
    \item 探索异构 UAV 场景，考虑不同类型 UAV 的计算能力、通信能力和能耗特性差异。
    \item 研究动态拓扑下的多 UAV 协同问题，考虑 UAV 的加入和退出对系统性能的影响。
\end{enumerate}

\section{本章小结}
\label{sec:summary-chap06}

本章总结了本文的研究工作和主要贡献，并展望了未来研究方向。首先回顾了基于 Attention-MAPPO 的双层 MARL 框架及其系统模型；随后总结了实验中体现出的公平性、能耗、MBS 负载和鲁棒性方面的综合折中优势；最后提出了细粒度 Pareto 扫描、三维轨迹控制、拉格朗日乘子自适应更新、服务缓存和内容分发协同优化等后续研究方向。
