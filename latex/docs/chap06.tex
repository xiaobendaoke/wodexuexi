\conclusionchapter
\label{cha:conclusion}

本文主要研究了无人机集群空地协同计算系统统一建模问题、自然覆盖需求感知协同轨迹规划问题、批量算力共享二元字典序任务分配问题以及跨时隙持续排队协同控制问题。主要工作如下：

\begin{enumerate}
\item 建立了面向时限计算服务的无人机集群空地协同计算统一数学模型与受控双协议评价体系，解决了空间自然覆盖关联、无线信道传输与异构节点执行负载耦合下的受控归因建模问题。构建了最近邻自然覆盖关联准则、离散机动防碰修复算子与频段隔离视距通信模型，证明了最小安全间距约束下关联集合的互斥完备划分性质；统一刻画了机载本地、邻机中继与宏基站回传三类执行路径，构建了单时隙批量等份算力共享（协议 I）与跨时隙先占式最早截止期优先（EDF）串联排队（协议 II）两类互补负载模型，并证明了端到端截止期满足率双因子精确分解与同源工作负载配对差分定理。

\item 提出了融合感知范围未覆盖需求扩展观测与精简下层协同的分层多智能体强化学习轨迹规划方法，克服了局部关联观测对覆盖圈外活跃需求不可见所导致的预接纳空间感知盲区不足。基于协议 I 从策略梯度可观测性角度证明了原始已关联观测对圈外需求分布的梯度盲区性质；在不放宽物理覆盖半径与固定观测维度的前提下，按距离升序将感知范围内未覆盖活跃终端填入上层关系自注意力网络的空闲槽位，并与下层无注意力精简 MAPPO 卸载策略协同训练，通过盲测确认配对仿真实验验证了所提方法对端到端截止期满足率与用户服务公平性的显著提升效果。

\item 提出了基于严格二元字典序全批次真实重评估的多轮协同迭代任务分配算法（MC-ITR），解决了单时隙批量等份算力共享下跨机迁移引发同批时延外部性及自利分配失配的问题。建立了超时请求总数优先、平均归一化时延次之的严格二元字典序目标，推导了单请求跨机迁移的精确时延外部性增量分解，严格证明了算法单步严格字典序下降性、有限步终止性与单请求邻域局部最优性，并通过标准快照、穷举校验快照与冻结轨迹桥接快照仿真实验验证了算法削减超时请求的有效性。

\item 提出了融合两轮规划知识蒸馏、共同随机数反事实辅助 PPO 微调与先验裁剪模型预测控制的跨时隙动态排队协同控制框架，解决了突发到达与历史队列持久耦合下冷启动探索困难、梯度方差高及滚动规划开销大的问题。构建了通信释放时刻递推结合节点工作守恒先占式 EDF 推进的两阶段快速近似模型与槽位置换同变双分支策略网络，证明了槽位置换同变性、共同随机数反事实组中心化的外生扰动消去性质及幂次先验校准的严格保序性，并通过盲测配对仿真实验验证了所提框架在提升截止期满足率与缩减在线决策耗时方面的优越性。
\end{enumerate}

基于以上研究内容，本文主要做出以下创新：

\begin{enumerate}
\item 建立了端到端时限服务双因子分解理论并提出了感知范围未覆盖需求扩展观测的分层协同轨迹规划方法。在以往有关无人机辅助边缘计算轨迹规划的研究中，往往假设全局终端完全已知或仅观测已覆盖终端而忽视圈外需求盲区，本文在不扩大物理覆盖半径与固定观测维度下按距离补入感知范围内未覆盖活跃需求并与精简下层协同优化，有效消除了预接纳感知混叠。

\item 建立了计入同批算力共享外部性的严格二元字典序任务分配模型并提出了全批次重评估多轮协同迭代算法（MC-ITR）。在以往有关多无人机协同任务分配的研究中，往往将多维指标线性加权或仅按单任务个体时延改善执行贪心迁移，本文精确刻画了单请求迁移对源节点与目标节点同批其余任务的算力外部性，通过全批次字典序重评估保证了系统全局超时指标的严格单调改善与邻域局部最优性。

\item 提出了融合两轮规划知识蒸馏、共同随机数反事实辅助微调与先验裁剪模型预测控制的跨时隙持续排队协同控制方法。在以往有关动态边缘计算强化学习控制的研究中，往往采用单时隙即时清空假设且易受冷启动探索低效与高状态方差制约，本文在槽位置换同变双分支网络上结合在线状态聚合蒸馏与同源随机流反事实组中心化，实现了零前瞻快速推理与低开销滚动规划的高效统一。
\end{enumerate}

在未来的研究中，还将围绕复杂低空环境适配、跨协议统一闭环建模与机载嵌入式实时验证开展进一步探索：一方面结合城市三维建筑高程地图与概率视距/非视距阴影衰落信道开展三维避障轨迹规划，并将移动终端演化、动态服务缓存预取与跨时隙先占式排队纳入统一端到端训练闭环；另一方面采用增量算术加速与编译型并行内核压缩求解耗时，显式计入非理想信令与推理时延，结合硬件在环平台与真实无人机集群飞行试验检验所提方法的工程实用性。
