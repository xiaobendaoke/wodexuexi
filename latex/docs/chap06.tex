\chapter{总结与展望}
\label{cha:conclusion}

\section{工作总结}
\label{sec:summary}

本文提出了一种基于 Attention-MAPPO 的多无人机 MEC 轨迹与任务卸载协同优化框架。通过将轨迹控制和请求级卸载解耦为两个协同决策层，并在正式评估中采用最近 UAV 兜底接入规则，该框架降低了直接端到端联合动作建模的结构复杂度，使所有 service request 均被系统接入并尝试处理，同时保留真实链路距离对时延和能耗的影响。

本文的主要工作和贡献包括：

\begin{enumerate}
    \item 提出了基于 Attention-MAPPO 的双层 MARL 框架，将轨迹控制与请求级卸载解耦为上层和下层两个协同决策层，降低动作空间复杂度。
    \item 设计了质量感知动作掩码和拉格朗日约束机制，分别处理不可行动作屏蔽和 DSR-MBS 负载权衡问题。
    \item 显式建模了 UAV 飞行能耗、UE 电池动态、WPT 机制和服务兜底接入过程，用处理率、强制接入比例、request-weighted DSR 和 MBS 负载共同刻画服务表现。
\end{enumerate}

实验结果表明：
\begin{enumerate}
    \item 在 force-admission 扩展基线矩阵中，所有方法的服务请求处理率均达到 100\%，说明兜底接入机制能够将未自然覆盖的 service request 纳入处理链路；该处理率不等同于 deadline 满足率。
    \item 本文方法在全服务接入口径下取得最高公平性（0.9452）、最低 UAV 侧能耗（49.98M）和最低 MBS 负载比例（3.59\%），同时保持 0.3762 的 request-weighted DSR，体现了低能耗、高公平性和低 MBS 依赖的综合折中优势。
    \item 与 IPPO 和 Vanilla MAPPO 相比，本文方法分别提高 DSR 约 35.3\% 和 30.7\%，并显著降低 MBS 依赖；与 Joint MAPPO 和 Uniform 相比，本文方法虽然不是最高 DSR，但能耗和 MBS 负载明显更低，公平性更高。
    \item force-admission 主配置与消融结果进一步表明，上层轨迹控制主要改善自然覆盖水平和空间公平性，下层请求级卸载主要调节本地、协作与 MBS 执行分布；Lagrange 软约束对抑制 MBS 依赖最关键。
    \item 端到端 \texttt{joint\_mappo} baseline 在 force-admission 矩阵中取得较高 DSR（0.4163），但 reward、能耗、公平性和 MBS 负载均明显劣于分层策略，说明直接联合轨迹--卸载动作学习存在更高综合代价。
\end{enumerate}

\section{未来展望}
\label{sec:future-work}

本文工作仍可从以下方向进一步扩展：

\begin{enumerate}
    \item 在更多 DSR 阈值和权重组合上进行细粒度 Pareto 扫描，以更好地理解 DSR-能耗-公平性之间的权衡关系。
    \item 扩大 vanilla/attention/joint MAPPO 补充实验的 training seeds 和 workload seeds，以获得与主实验一致的统计规模，提高实验结论的可靠性。
    \item 引入三维轨迹控制以更好地模拟真实部署环境，考虑 UAV 飞行高度的变化对通信和能耗的影响。
    \item 研究更高效的 Lagrange 乘子自适应更新策略，以提高约束优化的收敛速度和稳定性。
    \item 将服务缓存和内容分发纳入协同优化框架，实现轨迹、卸载、缓存和资源分配的全面协同优化。
    \item 探索异构 UAV 场景，考虑不同类型 UAV 的计算能力、通信能力和能耗特性差异。
    \item 研究动态拓扑下的多 UAV 协同问题，考虑 UAV 的加入和退出对系统性能的影响。
\end{enumerate}

\section{本章小结}
\label{sec:summary-chap06}

本章总结了本文的研究工作和主要贡献，并展望了未来的研究方向。首先回顾了本文提出的基于 Attention-MAPPO 的双层 MARL 框架及其 force-admission 正式评估口径；然后总结了实验结果，验证了该框架在全服务接入条件下的公平性、能耗和 MBS 负载折中优势；最后提出了未来的研究方向，包括细粒度 Pareto 扫描、三维轨迹控制、Lagrange 乘子自适应更新、服务缓存和内容分发协同优化等。
