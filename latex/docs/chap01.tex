\chapter{绪论}
\label{cha:introduction}

\section{研究背景与意义}
\label{sec:background}

无线通信在过去 30 年经历了飞速发展阶段，促进了社会和商业的发展，重塑了人们的生活方式。从 2G 时代开始采用数字信号，提供语音和短信服务，到 3G 技术使得移动网络支持更高速的数据传输，推动了智能手机和移动互联网的发展，再到 4G 网络大大提升了数据传输速度，支持高清视频、流媒体等应用。无线移动通信已经成为现代社会发展的重要支柱。

目前，第五代移动通信技术（The 5th Generation Mobile Communication Technology, 5G）的商用 \cite{ericsson20205g}，使得无线通信的发展已经迈入了一个崭新的阶段。国际电信联盟（International Telecommunication Union, ITU）为 5G 定义了三大应用场景：增强移动宽带（enhanced Mobile Broadband, eMBB）、超高可靠低时延通信（Ultra-Reliable and Low Latency Communication, URLLC）和海量机器类通信（massive Machine Type Communication, mMTC）\cite{3gpp20205g}。其中，eMBB 主要关注提升用户的移动宽带体验，尤其是在高密度场景下；URLLC 主要针对那些对通信可靠性和延迟要求极高的应用场景；mMTC 则是针对大量低功耗、低成本设备的通信需求。

随着 5G 技术的快速发展和迭代，无人机（Unmanned Aerial Vehicle, UAV）辅助通信系统逐渐成为未来通信网络的重要组成部分 \cite{zeng2016wireless, mozaffari2019tutorial}。无人机因其灵活性、低成本和高机动性，在多个领域展现出巨大的应用潜力，提供了广阔的发展前景，诸如在军事方面执行侦察任务，在自然灾害救灾方面提供紧急通信服务以及在工业物联网方面进行收集和传输物联网设备的数据等 \cite{li2020uav}。虽然无人机辅助通信在多种应用场景中展现出巨大潜力，但其在资源分配方面仍存在诸多待解难题。其中，频谱管理是关键问题之一。由于无人机数量不断增加，其频谱资源需求剧增，如何高效地分配有限的无线频谱以避免干扰、提高通信质量是当前研究的重点。其次，功率控制也是一个重要挑战。无人机通常依赖电池供电，而无线通信的功率消耗对无人机的续航时间影响极大，因此需要优化路径规划策略和功率分配策略，以在延长续航时间的同时确保通信质量。此外，在用户调度方面，随着无人机网络用户数量的增加，如何有效实现智能调度和用户接入，保障通信的公平性和稳定性，也是亟待解决的问题。

近年来，深度强化学习（Deep Reinforcement Learning, DRL）作为一种结合了深度学习和强化学习的先进技术，在解决复杂的决策问题中表现出色 \cite{mnih2015human}。得益于深度学习的特征提取能力和强化学习的决策能力，DRL 在诸如游戏、机器人控制、无线通信等多个领域取得了显著的成功 \cite{silver2016mastering, levine2016end, ye2020deep}。无人机辅助通信系统在实时性、可靠性和覆盖范围等方面对资源管理提出了极高的要求。尤其是在大规模、多用户、高密度和快速变化的环境下，传统的资源分配方法如静态的频谱分配、固定功率控制等，往往无法满足无人机网络的实际需求。并且无人机的移动性和任务需求的变化使得其通信网络常常处于一个高度动态的状态。如何在有限的频谱资源和功率资源条件下，实现对无人机的公平和高效调度，是一个极具挑战性的任务。在资源分配和动态决策等问题上，DRL 展现出独特的优势，能够处理那些传统算法难以应对的复杂情境。鉴于无人机通信环境的高度动态性与资源优化问题的复杂性，引入深度强化化学习方法以实现资源的智能化分配，具有重要的研究价值和实际意义。

在多无人机 MEC 系统中，服务质量并不只由单一因素决定。无人机轨迹会影响 UE-UAV 链路速率、协作无人机可达性、UAV-MBS 回传质量以及区域覆盖公平性；请求卸载策略则会进一步决定任务时延、UAV 计算负载、UAV 侧能耗、宏基站负载和截止期满足率。因此，轨迹控制和任务卸载之间存在强耦合关系 \cite{hu2019uav, yu2020joint}。若只优化轨迹，系统可能获得较好的覆盖，却仍然将大量请求回退到 MBS；若只优化卸载，策略只能被动适应当前 UAV 分布，无法主动创造更好的协作机会。如何设计高效的多智能体强化学习模型，以增强 UAV 辅助通信的智能资源管理能力，是未来研究的重要方向之一。

\section{国内外研究现状}
\label{sec:related_work}

随着无人机的迅速发展，特别是在 5G 及未来 6G 网络中，无人机辅助通信作为一种关键技术，受到了广泛关注 \cite{zeng2016wireless, mozaffari2019tutorial}。在无人机辅助通信系统中，现有研究主要聚焦于无人机部署、轨迹优化、系统吞吐量提升及能量消耗控制等优化问题。针对资源分配与运动轨迹优化的联合优化问题，其本质可归类为具有高度非线性与组合特性的混合整数非线性规划（Mixed Integer Non-Linear Programming, MINLP）问题，常规优化方法难以在合理时间内获得全局最优解。

\subsection{传统优化方法研究现状}

目前，不同研究利用数学优化理论对该组合优化问题进行求解优化。Trotta 等人 \cite{trotta2018uav} 提出了一种基于博弈论与群体移动模型的空中网格网络部署方案，该方案考虑了无人机之间的协作程度，并制定了相应的充电调度策略。Lai 等人 \cite{lai2019uav} 提出了一个适应性和公平部署无人机的方案，以解决无人机和用户之间关联的不平衡问题。Wang 等人 \cite{wang2019uav} 提出了一种集中式贪婪搜索方案，在不连续空间中启发式地获得无人机的最小数目及其次优位置，之后采用分布式运动算法使每架无人机能够在连续空间内自主控制其朝着最佳位置运动。Yang 等人 \cite{yang2019uav} 研究了高密度区域的无人机流量卸载问题，通过基于泊松-均匀分布构建了异构流量的分布模型，并通过优化无人机的部署高度，将三维部署问题转化为二维部署问题，以缓解网络拥塞问题。Lee 等人 \cite{lee2020uav} 基于竞争聚类与 Stackelberg 博弈，提出了一种无人机辅助 NB-IoT 系统的优化方法，实现了无人机位置调整与资源分配的联合优化。Kumar 等人 \cite{kumar2020uav} 研究了毫米波 UAV 网络中的动态资源分配问题，采用拉格朗日对偶分解方法求解全局最优解，并在计算复杂度较高的情况下，提出了一种收敛速度更快的次优解方案，在保证最低用户速率的前提下优化系统总吞吐量。

为进一步提高频谱资源利用率，部分研究将 NOMA 技术应用于无人机辅助通信系统。Duan 等人 \cite{duan2020uav} 提出了一种基于 K-means 聚类与多对多匹配算法的多无人机辅助物联网 NOMA 资源分配方案，以提高上行链路传输效率。Qin 等人 \cite{qin2021uav} 研究了 UAV 轨迹优化与资源分配的联合优化问题，提出了一种基于 C-NOMA 的异构 AGIN 架构，以提升系统吞吐量。Guo 等人 \cite{guo2021uav} 研究了无人机辅助移动边缘计算系统（Mobile Edge Computing, MEC）中的 NOMA 资源管理问题，并利用逐次凸逼近（Successive Convex Approximations, SCA）解决轨迹和功率分配的联合优化问题，同时结合差分凸规划理论（the Difference of Convex Programming Theory）获得次优解。此外，部分研究针对无人机辅助 MEC 系统中的资源分配、轨迹设计、用户关联及动态任务卸载等优化问题展开了深入探索 \cite{hu2019uav, yu2020joint}。

上述对组合问题进行求解优化存在一定的局限性，在复杂的通信网络中，实时获取信道状态信息（Channel State Information, CSI）和无人机的实时位置，是不现实的 \cite{li2020uav}。基于博弈论的无人机网络部署方案需要无人机之间进行频繁的信息交互，这样使得信令开销过大导致能量消耗增加，进而影响 UAV 网络的持续运行能力。此外，基于启发式算法的无人机网络资源分配方案，求解过程需要进行多次迭代，并且随着无人机数量的增加，需要进行的迭代次数呈指数级增长，为了能够快速求解只能退而求得次优解。因此，在实际通信场景中，传统数学优化方法在 UAV 辅助通信资源分配中的适用性受限，其主要挑战包括计算复杂度高、全局状态信息难以获取及算法收敛速度较慢等。

\subsection{深度强化学习方法研究现状}

近年来，DRL 在复杂决策问题中的优越性促使研究者将其应用于 UAV 辅助通信网络资源管理问题。He 等人 \cite{he2019uav} 提出了一种基于 Q-learning 的无人机轨迹优化算法，以最优路径规划降低数据传输时延。Liu 等人 \cite{liu2019uav} 在目标跟踪任务中将无人机路径规划建模为马尔可夫决策问题，并采用 DQN（Deep Q-Network, DQN）方法，以优化无人机的路径规划策略。Li 等人 \cite{li2020uav} 构建了两层深度强化学习框架，以优化无人机辅助无线传感器网络的数据采集效率。针对灾害环境下的应急通信，Kim 等人 \cite{kim2020uav} 提出了一种基于 DQN 的无人机路径优化方案，以确保受灾用户能够在极端环境中与救援队实现高效通信。Li 等人 \cite{li2021uav} 提出了基于深度强化学习的均场博弈（Mean Field Games, MFG）算法，利用深度神经网络优化无人机的功率控制策略，以最小化干扰并提升能量效率。由于无人机间的信息交换难以实现、全局状态信息存在时延，Fan 等人 \cite{fan2021uav} 提出了容迟多智能体深度强化学习（Delay-Tolerant Multi-Agent DRL, DT-MADRL）算法，以联合优化无人机的轨迹和传输控制策略。Ahmad 等人 \cite{ahmad2021uav} 针对 B5G 无人机辅助通信系统，提出了一种高效的基于 DRL 的深度确定性策略梯度（Deep Deterministic Policy Gradient, DDPG）机制，实现以能量效率和平均吞吐量最大化为双重目标实现资源的最优分配。Ghomri 等人 \cite{ghomri2021uav} 提出了一种基于最近策略优化（Proximal Policy Optimization, PPO）的 DRL 算法，以优化 NOMA-UAV 网络的能效（Energy Efficiency, EE）同时兼顾了远近公平性。

在 MEC 任务卸载与资源分配方面，Huang 等人 \cite{huang2021uav} 提出了一种基于深度强化学习的在线卸载框架，优化无人机作为 MEC 服务器的任务调度。Khurshid 等人 \cite{khurshid2021uav} 利用了一种基于连续动作空间的 DDPG 方法优化了 UAV-MEC 系统中无人机三维布局与任务卸载策略。Liu 等人 \cite{liu2021uav} 研究了一种多维联合优化方法，涵盖无人机悬停点选择、任务收集时间比例、信道选择、任务卸载策略等，以提高 UAV 辅助 MEC 的效率。此外，部分研究结合智能反射面（Intelligent Reflecting Surface, IRS）技术，进一步提升无人机辅助 MEC 系统的通信性能 \cite{wu2021uav}。

\subsection{多智能体强化学习方法研究现状}

多智能体强化学习（Multi-Agent Reinforcement Learning, MARL）作为 DRL 的重要分支，在多无人机协同决策问题中展现出独特优势。与单智能体 DRL 相比，MARL 能够更好地建模多无人机之间的协作与竞争关系，实现更高效的资源分配和任务调度。

近年来，MARL 在无人机辅助通信领域的应用逐渐增多。Liu 等人 \cite{liu2026multi} 提出了基于 MARL 的多无人机协同优化框架，通过分布式决策实现全局最优。黄子祥等 \cite{huang2026madr} 针对应急场景提出基于 MADRL 的多无人机协同计算卸载策略，联合优化卸载比例、飞行角度和速度，并使用 Jain 公平性指数衡量负载均衡。尤昕阳等 \cite{you2026soft} 提出基于柔性 Actor-Critic 的多无人机协同 MEC 任务卸载方案，联合决策任务卸载比例、无人机选择、传输功率与算力分配。王义君等 \cite{wang2026ccah} 提出基于协同缓存自适应的分层多元宇宙优化算法（CCAH-MVO），在三层网络架构下协同优化缓存、卸载和资源分配。曾耀平等 \cite{zeng2026uav} 采用 Stackelberg 博弈方法联合优化 UAV 部署和 UE 卸载策略。李侍阳等 \cite{li2026sensing} 面向感知与 AI 协同任务，提出基于 MILP 和 SCA 的多维资源联合优化算法。

在 MARL 算法方面，MAPPO（Multi-Agent Proximal Policy Optimization）作为 PPO 的多智能体扩展，在多无人机协同任务中表现出色 \cite{yu2021surprising}。MAPPO 通过集中式训练分布式执行（Centralized Training with Decentralized Execution, CTDE）的范式，在训练阶段利用全局信息优化策略，在执行阶段仅依赖局部观测进行决策，有效平衡了全局最优与分布式执行的需求。

\subsection{现有研究的局限性}

综上所述，尽管目前国内外已有许多无人机辅助通信系统的研究，但仍然存在诸多问题亟待解决。首先，在动态环境与干扰较强的场景下，无人机辅助 MEC 系统中的计算卸载与资源分配联合优化问题尚未得到充分研究。其次，尽管深度强化学习在无人机辅助通信领域展现出巨大潜力，但在大规模无人机网络中的计算复杂度、泛化能力及实时决策能力仍面临挑战。此外，现有研究大多忽略终端设备的能量动态，导致系统长期运行不可持续。

具体而言，现有研究存在以下局限性：

\begin{enumerate}
    \item \textbf{动作空间耦合问题}：在多无人机 MEC 系统中，连续轨迹控制与离散卸载决策的合并导致动作空间维度急剧增加，传统 DRL 方法难以有效处理这种混合动作空间。
    \item \textbf{约束处理不足}：现有研究大多采用简单惩罚项处理约束，缺乏对约束违反程度的量化分析和可解释的约束权衡机制。
    \item \textbf{能量动态忽略}：多数研究假设终端设备能量无限，忽略了 UE 电池动态和无线能量传输机制，导致系统长期运行不可持续。
    \item \textbf{可解释性缺失}：深度强化学习模型的决策过程缺乏可解释性，难以分析无人机之间的协作关系和决策依据。
\end{enumerate}

与上述工作不同，本文关注如何将强耦合的轨迹-卸载问题拆分为可训练、可复现、可解释的双层 MARL 框架，并显式建模终端设备的能量动态以维持系统的持续运行。本文提出基于注意力机制的 MAPPO 框架，通过注意力机制建模无人机之间的协作关系，设计请求级质量感知动作掩码和拉格朗日约束机制，以解决上述局限性。

\section{研究内容及贡献}
\label{sec:contributions}

本文的主要贡献如下：

\begin{enumerate}
    \item 提出一种基于 Attention-MAPPO 的多 UAV MEC 轨迹与任务卸载协同优化框架，将轨迹控制和请求级卸载拆分为上层 attention-MAPPO 和下层 constrained attention offload MAPPO 两个协同决策层，以降低直接联合建模的动作耦合复杂度。
    \item 设计请求级质量感知动作 mask，对明显不可行的 cooperative UAV 与 MBS 动作进行运行时屏蔽，减少无效探索。消融实验表明，mask 会改变 MBS load ratio 和协作卸载比例。
    \item 在下层奖励中引入 Lagrange 约束机制，将 DSR 和 MBS load ratio 纳入可解释的约束权衡。消融实验表明，去除 Lagrange 约束后 MBS load ratio 从 11.0\% 上升至 17.1\%。
    \item 补充实现上层 vanilla MAPPO、attention 权重可视化和端到端 joint MAPPO baseline，用于分析 attention 机制的作用边界和直接联合动作学习的训练难度。
\end{enumerate}

此外，本文在系统模型中显式考虑 UAV 飞行能耗、UE 电池动态和 WPT 机制，并基于 training seed 与 workload seed 的成对统计单元（$N=30$）报告均值、95\% 置信区间、paired t-test 和 Wilcoxon 检验。
