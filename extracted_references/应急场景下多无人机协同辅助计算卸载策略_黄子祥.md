# 应急场景下多无人机协同辅助计算卸载策略 \*

黄子祥1 ，张新有2

（1．西南交通大学唐山研究院，河北唐山063000;2．西南交通大学计算机与人工智能学院，四川成都610000）

摘要：某地突发网络故障的紧急情况下，可以通过部署无人机（UAV）充当临时基站与边缘计算节点恢复网络。单无人机处理能力与覆盖范围均存在较大限制，而无人机协同可以有效地解决此类问题。对应急场景下无人机协同计算卸载的问题，提出一种空地一体化架构，并创新性地设计一种多智能体深强化学习（MADRL）算法联合优化卸载决策、无人机的飞行角度、速度等在考虑公平性负载的前提下降系统的卸载时延、系统能耗。仿真结果表明：该算法与随机处理相比，系统总代价降低了约77％，与深确定性策略梯度（DDPG）算法相比，系统总代价降低了约46 ％ 。充分地展现了本文卸载策略在极端场下的优越性。

关键词：边缘计算；深度强化学习；无人机协同；轨迹优化；计算卸载

# Multi-UAV collaborative computing offloading strategy in emergency scenarios \*

HUANG Zixiang 1 ，ZHANG Xinyou2

（1． Tangshan Research Institute，Southwest Jiaotong University，Tangshan 063000，China； 2． School of Computer and Artificial Intelligence，Southwest Jiaotong University，Chengdu 610000，China）

Abstract：In the event of a sudden network failure in emergency scenarios，the network can be recovered by deploying unmanned aerial vehicles（UAVs）as temporary base stations and edge computing nodes． A single UAV exhibits significant limitations in the processing capacity and coverage range，while multi-UAV collaboration can effectively solve such problems． Aiming at the problem of UAV collaborative computing offloading in emergency scenarios，an air-ground integration architecture is proposed，and a multi-agent deep reinforcement learning （MADRL）algorithm is innovatively designed to jointly optimize offloading decisions，as well as the flight angle， and speed of UAVs，so as to reduce system offloading delay and energy consumption while considering load fairness． The simulation results show that compared with random processing，the proposed algorithm reduces the total system cost by about 77 ％ ，and compared with the deep deterministic policy gradient（DDPG）algorithm，it reduces the total system cost by about 46 ％ ，which fully demonstrates the superiority of the proposed offloading strategy in extreme scenarios．

Keywords：edge computing；deep reinforcement learning；UAV collaboration；trajectory optimization；computation offloading

## 0 引言

随着5G时代的到来，无人驾驶、自动导航、身份识等各类新兴的计算密集型应用极大地方便了人们的生活。在此背景下，终端产生的数据量也呈现井喷式增长，这也计算受限的终端设备带来了严峻的挑战。随着移动边缘算（mobile edge computing，MEC）这一新范式的出现［1］ ，不仅弥补了终端计算能力不足的问题，与云计算相比还拥较低的延迟以满足时延敏感型任务的计算需求。MEC以将任务卸载到距离用户较近的MEC服务器，从而提高务质量。但对于一些偏远山区等复杂场景来说，实时获可靠的MEC服务是比较困难的。

无人机（UAV）具有机动灵活、响应迅速、覆盖范围等优点，已被广泛应用于农业作业、交通监控、航拍摄影等各类物联网场景［2］。越来越多的研究人员开始将无人机应用在边缘计算领域，并把具有一定计算机资源的无人机充当MEC服务器应用在多样的场景当中。多个无人机或无人机群通过协同分工合作，在处理更为复杂的任务上现了杰出的能力。由于极端场景的复杂性、信息的多样性以及信息处理的实时性要求，对无人机之间的协同处理能力提出了更高的要求。

对于多无人机协同场景来说，状态空间通常维度较高，求解也极为复杂。传统的启发式算法难以从大的解空间选择较好的决策［3］ 。深度强化学习（deep reinforcementlearning，DRL）方法近年来在分类、回归等领域取得了巨大突破［4］，即使没有先验知识，智能体也可以自动与复杂的环境进行交互，以学习最优策略。对于多无人机辅助计卸载这一热点问题，研究人员已经提出了许多卸载方案，文是对该问题前期工作的介绍。

## 1 相关工作

近年来，无人机集成MEC技术取得了一系列进展，对无人机辅助任务卸载模型，以往的研究均集中在时延、能耗、吞吐量、服务质量等方面的优化。在文献［5］研究了一种基于无人机的云计算系统，利用逐次凸近似策略，旨在足应用程序的服务质量要求的前提下最小化无人机移动能耗。文献［6］提出了一种交替优化算法，以迭代的方式联合优化计算资源调度、带宽分配和无人机的轨迹来最小化无人机与用户的能耗加权和。文献［7］提出了一种创新无人机MEC系统，涉及物联网设备、无人机和边缘云（edgecloud，EC）之间的交互。基于逐次凸近似的有效算法使所有物联网设备的服务延迟与无人机能耗的加权和最小化。文献［8］提出了一种新的基于时分多址（TDMA）的工作流模型，该模型允许在无人机辅助系统中并行传输和执行，应用流水车间调度技术最大限度地减少无人机的总能耗。在上述文献中，研究人员均采用传统的优化或启发式算来解决无人机辅助MEC网络的资源分配和卸载决策等问题，上文已提到该类方法不适合应用与高维动态且复杂建模当中。

由于控制决策和资源优化的优势，DRL被广泛认为应用于复杂的动态环境，是解决策略控制问题的理想工具［9］，同时，DRL结合MEC已成为一个热门的研究课题。文献［10］提出一种新颖且高效的基于DRL 的方法—DRL-EC3。提出的方法在综合考虑通信覆盖、公平性、能耗和连通性的情况下，最大化了一种新的能效函数。文献［11］通过优化每架无人机的轨迹和卸载决策，共同最大化所覆盖的用户设备（user equipment，UE）之间的地理公平性，同时最小化UE的总体能耗。

上述文献采用DRL算法处理无人机的卸载问题，明的问题集中在以下几个方面：

1）上述研究大多数使用的无人机—地面信道模型是循自由空间路径损耗模型链路的确定性视距（line of sight，LOS）信道，在实际应用中，无人机与地面UE常常有障碍遮挡，不符合极端场景下的特征。

2）未考虑地面用户可能存在一定的移动性，也未考虑无人机的负载公平等。

3）能耗考虑不全，未将无人机的飞行能耗等作为考虑因素，与实际情况相差较大。

为了优化上述研究存在的一些问题，本文考虑某地特殊原因导致地面基站被摧毁的极端场景，使用多无人协同辅助地面用户进行计算卸载。在无人机负载公平性前提下最小化任务的处理时延、用户与无人机的总能耗。创新性的提出一种多智能体DRL （multi-agent DRL，MADRL）算法应用于本文的计算卸载模型中，主要工包括：

1）基于非视距（NLOS）链路提出一种多无人机协同助MEC的空地一体化架构，优化极端场景下的任务卸载型。与传统模型不同，本文地面用户具有移动性。

2）将非凸计算卸载问题转换为部分可观测马尔可决策过程（partially observable Markov decision process，POM-DP）问题。针对场景创新性的设计一种MADRL对各个人机的轨迹、卸载决策等进行优化，每个智能体可以根据部实时观察做出决策，再设计一种状态标准化算法对状进行归一化。通过集中训练和分散执行技术降低总体训练成本，从而最大化总奖励值。

3）进行大量的仿真实验。与其他算法对比本文算在该场景下的时延与总能耗方面表现最优。

## 2． 2． 1 时延计算模型

在本文的无人机辅助卸载模型中，卸载时采用的是部分卸载的方式，即卸载的比例在0～1。UE需要把任务传输至无人机才可进行卸载工作，而数据把任务传输至无机所需要的时间成本

$$
T _ { t r a } = \frac { p D _ { n } } { R _ { n } }\tag{3}
$$

式中p为卸载到某无人机的比例。任务传输至无人机后，无人机即可开始进行卸载处理，而该卸载部分在无人上的处理时延为

$$
T _ { e x e } = \frac { p C _ { n } } { f _ { n } ^ { r } }\tag{4}
$$

式中 $\boldsymbol { f } _ { \scriptscriptstyle n } ^ { r }$ 为该无人机携带的MEC的计算能力。本文考的是一个任意比例卸载的模型，即 $( 1 - p )$ 比例仍在本执行，考虑其未卸载部分的本地执行时间

$$

式中 $f _ { n } ^ { l }$ 为UE的CPU频率。参考文献［12］，由于任务计算处理完返回的数据结果通常非常小，可以忽略其下载数据的时延。即可得出，在任意比例卸载时，总时延

## 3 联合轨迹与卸载决策的强化学习算法

## 3． 1 POMDP 设计

多无人机辅助UE 卸载的过程可以被建模为POM-$\mathrm { D P } ^ { [ 1 6 ] }$ 。其中，每个无人机都是一个智能体，根据自身的部观测，作出一系列的决策，再获得环境给出的奖励值。

整个系统达到最优。下文针对设计的观测／状态空间、动空间、奖励函数进行详细说明。

## 5 结束语

本文以极端场景下的无人机协同辅助卸载为背景，研究了该场景中公平性卸载下的最小化卸载时延与系统总耗问题。通过设计一种创新的MADRL算法有效地降低系统的时延与能耗。考虑到无人机在二维空间下运动的限性，后续将无人机的运动空间扩展到三维空间进行卸载研究。
