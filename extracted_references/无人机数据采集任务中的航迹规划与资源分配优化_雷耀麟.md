# 无人机数据采集任务中的航迹规划与资源分配优化

雷耀麟1，2，丁文锐3，罗祎喆4，\*，王玉峰3，刘思琪5，张芷兰1

(1.   北京航空航天大学 电子信息工程学院，北京 100191； 2.   中国电子科技集团第五十四研究所，石家庄 050081；

3.   北京航空航天大学 无人系统研究院，北京 100191； 4.   郑州大学 计算机与人工智能学院，郑州 450053；

5.   国网河南省电力公司新乡供电公司，新乡 453000)

摘 要：针对无人机（UAV）在应急场景中执行数据采集任务时，其电池容量有限、缓存空间有限，以及地面目标优先级动态变化所导致的无人机航迹规划与资源分配效果较差的问题，提出一种基于深度强化学习的无人机航迹规划与资源分配联合优化方法。考虑无人机任务中的通信、计算、飞行、数据缓存过程，构建相应的数学问题模型；针对无人机航迹规划与资源分配问题构建马尔可夫过程模型，设计相应的状态和行为描述及用于平衡无人机能耗和数据采集信息量的加权奖励函数；与贪婪算法和遗传算法等智能优化方法进行仿真对比。结果表明：所提方法能够使无人机在较短的任务时间内，以消耗相似或者较低的能量为代价，较大提升对地面用户的数据采集量。

关　键　词：无人机；资源分配；航迹规划；强化学习；移动边缘计算

无人机（unmanned aerial vehicle, UAV）作为不需要人类飞行员操控的轻量级飞机，具备低成本、鲁棒性强、可商购[1] 等优点。得益于其高机动性与高空通信优势，无人机在数据采集任务中的应用越来越广泛。例如，在电力巡检过程中[2]，通过规划无人机资源，并对无人机任务进行合理规划，可有效减少电力物联网的业务延迟和能耗。此外，无人机数据采集可用于无线传感器网络中的广域数据采集[3]，在传统方式中，每个传感器节点通过多跳传输将其监测到的数据传送到融合中心，其间，不仅需要传输自己的数据，还需要中继其他节点的数据，因此，传感器的电池可能会迅速耗尽，导致多跳网络失联。而通过将无人机作为移动融合中心，每个传感器节点都可以直接将观测数据发送给无人机，极大提升了无线传感网络数据采集的效率，具有较高的研究价值[4]。

无人机航迹规划与资源分配对数据采集有着至关重要的影响，一般优化的目标为最低能耗、最短飞行时间、最低时延等。无人机航迹规划常常与资源分配组合，从而最大化资源利用率，构成的组合优化问题的决策空间很大，因此，优化复杂度很高。无人机航迹规划与资源分配优化方法可以划分为基于图论的方法、基于优化方法的方法、基于人工智能的方法。其中，基于图论的航迹规划方法包括沃罗诺伊图算法、概率路线图算法、希尔伯特曲线算法等，该类方法将无人机执行任务所在的地理空间转换为图并搜索源和目的地之间的路径，优化目标一般为最大采集数据量、最小数据采集时间、最小能耗等[5-7]。基于优化方法的方法包括动态规划、分支定界和连续凸逼近算法，此类方法能够找到问题的最优解或次优解，但对于一些所有多项式复杂程度的非确定性问题都能在多项式时间复杂度内归约到的非确定性多项式时间完全问题，时间复杂度是指数级的，求解难度很高。当决策空间很大时，可以应用启发式方法来寻找可行解。在文献 [8]中，传感器被部署在一条直线上，将无人机的轨迹划分为不重叠的区间进行数据采集。使用动态规划优化数据采集的间隔，可以最大限度地减少无人机的飞行时间，并优化无人机的飞行速度和传感器发射功率。为了从尽可能多的传感器采集数据，Samir等[9] 提出了高复杂度的分支、归约和定界算法，以找到相对小规模场景下的全局最优解，开发了一种基于逐次凸逼近的有效求解算法，以获得更大网络的结果，并提出了一种扩展算法，在无人机初始和最终位置先验已知的情况下，进一步最小化无人机的飞行距离。Zhan 等[10] 研究了多个物联网设备的通信调度和发射功率分配的联合优化及在无人机物联网系统上进行数据采集的无人机航迹优化问题，提出了一种联合优化方法，以最大限度地减少受无人机能量约束的所有设备的最大能耗。

在应急场景中，环境往往是动态变化的，如受灾区域的地面目标优先级会在任务执行过程中随着卫星监测获取的新信息或相关人员的手动修改而变化。传统的优化方法往往难以解决这类问题，而强化学习方法是解决这类动态规划问题的有效途径之一，因此，对强化学习方法在无人机数据采集任务规划中的应用进行研究具有重要的意义和价值。Nguyen等[11] 设计了一种无人机辅助的物联网数据采集系统，采用基于强化学习的训练方法，在特定的覆盖范围内优化无人机轨迹和吞吐量。Fu等[12] 研究了支持无线充电功能的无人机在数据采集任务中的应用，提出了一种基于强化学习的方法对无人机进行规划，使其从分散在物理环境中的传感器设备中采集传感器数据。Bayerlein 等[13] 提出一种基于双深度 Q 网络的无人机航迹规划算法，用于在城市环境中从物联网设备采集数据。

综上所述，现有无人机数据采集相关研究仍存在 2点局限性：①多数研究仍以最优化理论或启发式智能优化方法实现无人机任务期间的航迹规划和资源分配。然而，随着传感器网络规模不断扩展及用户服务体验的不断升级，数据采集呈现出“高密度-低时延”的特点，传统优化方法逐渐不能满足其实时性的要求；②多数基于深度强化学习的研究是在无人机能量有限或工作时间有限的条件下优化无人机航迹，忽略了任务过程中的资源分配（计算资源和通信资源）问题，且大多未考虑无人机缓存空间的局限性。对此，本文提出一种基于深度强化学习的无人机航迹规划与资源分配联合优化方法，相关创新工作可总结如下：

1） 在现有无人机资源分配模型的基础上，进一步设计无人机数据采集模型和无人机边缘缓存模型，并充分考虑无人机飞行、通信、计算、数据采集、缓存等物理过程，构建无人机航迹规划与资源分配数学模型。

2） 在上述工作基础上，进行马尔可夫决策过程构建，设计相应的状态-行为空间，并提出无人机能耗与数据采集信息量加权的训练奖励函数，对两者进行平衡与调整。

3） 设计基于软决策/评价（soft actor critic, SAC）算法[14] 的决策算法训练框架，通过仿真实验，证明了本文方法可使无人机在消耗相近或者较小能量的情况下，有效提升数据采集量。

## 1　任务场景分析与建模

无人机数据采集任务场景如图 1所示，任务场景包含 1 个无人机、1 个地面处理单元和 N 个地面目标，无人机以拍摄图像的方式采集地面目标数据，地面处理单元可以接收无人机发送的数据并处理。无人机在一片固定大小的区域内执行数据采集任务时，由于无人机缓存空间有限，需要在采集数据的同时机上处理数据或传输至地面处理单元进行处理。考虑到无人机电池能量有限，而无人机空中飞行、盘旋、机上数据处理和数据传输都会消耗电池能量，因此，需要优化无人机航迹规划和资源分配。

4） 能耗模型构建。无人机能耗模型主要包括飞行能耗、数据传输能耗和计算能耗[16]。

飞行能耗指无人机终端执行任务时的机动能耗，参考目前主流研究，无人机的飞行能耗主要与各时刻速度有关。假设无人机终端在 t时刻的速度为 $\nu _ { t } .$ ，为便于处理，本节假设无人机在每个时间段内的速度保持不变，且忽略无人机的加速与减速过程，即无人机的飞行功率 $P _ { \mathrm { f } }$ 保持恒定。同理，无人机采集目标数据时在目标上空盘旋的功率 $P _ { \mathrm { h } }$ 也恒定，则可通过式(7)计算各时刻飞行能耗：

$$
E _ { \mathrm { f } , t } = P _ { \mathrm { f } } t _ { \mathrm { f } , t } + P _ { \mathrm { h } } t _ { \mathrm { h } , t } \qquad \forall t \in \mathcal { T }\tag{7}
$$

式中： $t _ { \mathrm { h } , t }$ 为时刻t内无人机的盘旋时间。

数据传输能耗指系统中无人机与中心处理单元间进行数据传输时的能耗。数据传输能耗与传输功率相关，由于无人机仅在空中盘旋时进行数据传输，数据传输能耗可以表示为

$$
E _ { \mathrm { T r } , t } = P _ { \mathrm { T r } , t } t _ { \mathrm { s } , t } \qquad \forall t \in \mathcal { T }\tag{8}
$$

式中： $P _ { \mathrm { T r } , t } \in \left[ 0 , P _ { \mathrm { T r , m a x } } \right]$ 为无人机在时间段 t内的传输功率。

$$
E _ { \mathrm { c } , t } = \eta _ { \mathrm { c } } F _ { \mathrm { c } , t } ^ { 3 } \left( t _ { \mathrm { f } , t } + t _ { \mathrm { s } , t } \right) \qquad \forall t \in \mathcal { T }\tag{9}
$$

式中： $\eta _ { \mathrm { c } }$ 为无人机边缘计算节点有效转换率； $F _ { \mathrm { c } , t } \in$   
[0, $F _ { \mathrm { c , m a x } } ]$ 。

7） 算法性能评价模型构建。对于无人机数据采集任务，需要建立算法性能评价模型来评估无人机在数据采集任务中的完成效果。选取回合总奖励、采集总信息量、飞行总能耗作为评价指标，构成算法性能评价模型。

$w _ { t }$ 为采集目标的信息量，即各目标优先级权重。

## 2.1　遗传算法

遗传算法[18] 是基于生物进化理论的一种优化算法，其通过模拟自然选择、交叉和变异等生物进化过程，以产生更好的解决方案。与其他优化方法相比，遗传算法具有 3大优势：①全局优化能力强：可以搜索全局最优解，而不仅仅是局部最优解；

②适应性强：遗传算法可以应用于各种类型的问题，且可以根据问题特性调整算法参数以获得更好的性能；③并行性强：遗传算法可以使用多个处理器或计算机同时计算，以提高求解效率。

具体到本文问题，每一个体是对无人机航路点和资源分配编码的结果，编码方式采用二进制编码，优化变量维度为 4T，在每一时间段内优化无人机航迹（横坐标 x与纵坐标 y）和资源分配（计算频率与传输功率）。编码位数依据 $\log _ { 2 } { ( V _ { \mathrm { u b } } - V _ { \mathrm { l b } } / A + 1 ) }$ V计算得到， 为变量， $V _ { \mathrm { u b } }$ 和 $V _ {  { \mathrm { l b } } }$ 分别为变量上界和下A界， 为变量优化精度。通过种群内的选择、交叉、编译得到子代，从而实现无人机航迹规划与资源分配的联合优化，并将目标函数最大化的子代作为最优解，具体算法流程如下：

## 3　基于深度强化学习的航迹规划与资源分配优化

智能优化方法虽然在多数资源优化问题中有较好的表现，但仍存在一定局限性，例如，对于高维度、非线性和非凸优化问题，遗传算法的求解效率可能会受到影响。此外，智能优化方法的时间复杂度往往较高，在时效性方面往往较差。为此，本文进一步引入深度强化学习机制，提出一种基于深度强化学习的无人机航迹规划与资源分配联合优化方法，并将无人机与环境的交互过程建模为马尔可夫决策过程，通过最大化每回合累积奖励的方法来提高无人机对地面目标的数据采集能力。

## 3.1　马尔可夫决策过程建模

为将深度强化学习应用于所提无人机航迹与资源优化问题，需要将优化问题建模为马尔可夫决策过程。在马尔可夫决策过程中存在一个智能体与环境交互，该过程可以表示为一个四元组 [s(t)，$\boldsymbol { a } ( t ) , \boldsymbol { r } ( t ) , \boldsymbol { s } ( t { + } 1 ) \big ] \odot$ 。其中，s(t) 为智能体在时隙 t 中的状态，状态可以是离散的或连续的，有限的或无限的； $a ( t )$ 为智能体可选择的行为；r(t) 为在某个状态下，执行某个动作后，环境反馈给智能体的奖赏或惩罚，即 $s ( t ) a ( t ) \to r ( t ) , s ( t + 1 )$ 为神经网络施加行为$a ( t )$ 后在下一个时隙中的状态。深度强化学习的目标是学习到一个最大化累积奖励的策略 $\pi : s  a .$ 即一个行为函数，输入当前状态可输出最优动作，其是一个状态到动作的映射。在本文所提问题中，上述马尔可夫过程的状态、行为和奖励定义如下。

## 3.1.1　状态定义

智能体需感知环境状态，从而做出决策，环境状态包括：

1） 无人机当前位置，其水平面内的二维坐标可表示为： $c _ { \mathrm { u } , t } = ( x _ { t } , y _ { t } )$ 。

2） 无人机剩余电池能量，当前时刻无人机电池能量通过上一时刻电池能量减去上一时刻内所消耗能量得到。

3） 无人机剩余缓存，每时刻无人机会将采集到的数据存储到缓存空间，也会通过机上处理和传输至地面处理单元处理。

4） 地面目标采集列表，地面目标图像信息若已采集，则标为 1，若未采集，则标为－1，由所有地面目标的采集标志位拼接得到地面目标采集列表。

5） 地面目标优先级，地面目标具有不同的优先级，不同优先级的信息量不同，由所有地面目标的优先级拼接得到地面目标优先级列表。

综上所述，无人机航迹规划与资源分配优化问题在t时刻的状态可以表示为

$$
\boldsymbol { s } ( t ) = \left\{ c _ { \mathrm { u } , t } , E _ { t } , C _ { t } , L _ { t } , \boldsymbol { B } _ { t } \right\}\tag{14}
$$

其中： $L _ { t }$ 为目标服务列表，指示地面目标是否已完成数据采集。

## 3.1.2　行为定义

智能体做出的具体决策行为包含：

1） 无人机坐标，在时刻 t决定下一时刻无人机位置，用二维坐标 $( x _ { t + 1 } , y _ { t + 1 } )$ 表示，决策变量也可以采用速度和航向，本节直接采用坐标，更便于处理。

2） 无人机计算频率和传输功率，计算频率对应无人机计算资源，传输功率对应无人机通信资源，直接影响各时刻无人机机上处理数据量和传输数据量。

综上所述，智能体在 t时刻的决策动作可以表示为

$$
a ( t ) = \left\{ x _ { t } , y _ { t } , P _ { \mathrm { T r } , t } , F _ { \mathrm { c } , t } \right\}\tag{15}
$$

目标函数对应深度强化学习方法中的奖励函r(t)数，在t时刻的奖励 可以表示为

## 5　结　论

1） 本文围绕无人机数据采集任务开展相应的航迹规划与资源分配优化，充分考虑了无人机飞行、通信、计算、数据采集等物理过程，并进行了相关数学模型构建。

2） 在现有 SAC框架的基础上，设计了无人机能耗与数据采集信息量加权的训练奖励函数，可通过合理分配权重进而对两者进行平衡与调整。

3） 对比仿真实验结果表明，相较于遗传算法和贪婪算法，所提的基于深度强化学习的无人机航迹规划与资源分配联合优化方法可使无人机在消耗相近或者较小能量的情况下，采集到较大的数据量。
